# 许可文本来源

`standard/` 内为 SPDX License List Data `v3.26.0` 的标准许可或例外文本，来源：
https://github.com/spdx/license-list-data/tree/v3.26.0/text

这些文本用于补充通知，不改变第三方组件的许可选择。第三方组件实际版权、附加通知和字体许可优先保留自 Cargo.lock 对应的发布源码，汇总于根目录 `THIRD-PARTY-NOTICES.txt`。

GCC GPL 与 Runtime Library Exception 文本用于 Windows MinGW 运行库说明；它们不是本项目原创部分的许可证。涉及 LGPL 的标准文本也不表示本应用选择了 LGPL，参见各组件原始 SPDX 表达式及项目许可说明。
