# TODO 与交付路线图

Eclipse 的重点是多屏工作区、低延迟串流、自托管连接和主机共享管理。先改善这些已有能力的稳定性，再扩展外设、平台与远程工具。

本文按当前实现重新整理，不将旧版计划当作待开发功能。**已实现表示代码和界面已有对应路径，不表示所有硬件、桌面环境和网络都已验收。** 正式包包含哪些改动，以[版本说明](releases/README.md)为准；开发分支可能先于正式发布。这里不承诺版本号或交付日期。

## 已有基础

| 分类 | 已实现的能力 | 适用范围与说明 |
|---|---|---|
| 连接与授权 | 局域网发现、IPv4 / IPv6 直连、公钥配对、密码与临时授权、撤销设备 | 原生串流无需第三方账号；发现设备不等于获准访问。 |
| 自托管公网连接 | WSS 目录、私人设备组与接入码、ICE / STUN、直连优先、TURN/UDP 中转 | 已实现 TURN；不同 NAT 与受限网络仍需持续验证，目前没有 TURN/TCP 或 TURN/TLS。 |
| 多屏工作区 | 多设备 / 多屏标签、逐屏配置、独立窗口、拆分合并、音源协调 | 并发串流受主机编解码资源限制；门户选屏受桌面授权约束。 |
| 虚拟显示器 | 按需创建与移除、名称与模式编辑、临时 / 持久、单屏布局恢复 | Windows 实验性功能，需要驱动；持久屏可在程序退出后保留。 |
| 会话与协作 | 逐会话键鼠 / 手柄权限、房主画质与显示器控制、游戏厅、悬浮会话中心 | Windows 支持同屏共享采集；键鼠空闲交接，手柄独立；面板尚无远端输入隔离。 |
| 音视频 | H.264 / HEVC / AV1、软硬件选择、协商回退、CBR / VBR、Opus | 格式取决于真实硬件能力；Windows HDR10，Linux 当前 SDR。 |
| 输入与外设 | 绝对 / 相对鼠标、快捷键捕获、图文剪贴板、手柄与运动传感器 | 外设受驱动和授权限制；没有手柄震动与自适应扳机。 |
| 后台与隐私 | Windows 主机服务、连接提醒与历史、结束后锁屏、便携配置 | Windows 本机键鼠优先；Linux 依赖已登录的桌面会话。 |
| 诊断与扩展 | HUD、历史曲线、分阶段与端到端估测、profiling 工具、独立插件 SDK | 软件显示回执不是物理光子测量；完整包自带默认关闭的 UU 与壁纸插件，源码独立维护。 |

具体使用方式见 [README](../README.md#核心功能) 和各功能文档。

## 近期重点：把日常体验做稳

这些项目是在已有功能上继续改善，不能视为已完成。

| TODO | 当前情况 | 完成判据 |
|---|---|---|
| 降低窗口模式延迟，定位偶发输入跟随变慢 | 已有分阶段 tracing、受控动态图与鼠标负载工具；全屏已有较好的实测基线，窗口合成等待和偶发输入问题仍在调查 | 同硬件、场景、分辨率、刷新率、码率和路径下对比，记录视频 / 输入尾延迟与帧间隔；保留可复现基线，防止全屏体验回退。 |
| 混合 DPI 迁屏与窗口恢复 | 已有窗口几何管理和上游 DPI 修复；真实系统快捷键迁屏、最大化 / 全屏切换仍需实机验证 | 不同比例与负坐标布局下，一次迁屏生效、尺寸合理；焦点、菜单与输入归属持续正确。 |
| 锁屏、桌面切换与无头主机恢复 | 已有桌面失效重建、无首图兼容采集和虚拟屏路径 | 覆盖登录 / 锁屏 / 解锁、RDP / 控制台切换、最后一块临时屏移除后的重连；首个错误可诊断，失败不影响其它会话或留下多余设备。 |
| 公网连接速度与失败解释 | 已并行候选发现与媒体准备，支持路径详情和中转 | 用不同 NAT、CGNAT、IPv6 与丢包环境记录连接各阶段耗时；目录在线、配对成功和媒体可达分别反馈。 |
| 多客户端与外设长稳 | 已有同屏采集、空闲键鼠交接、本机优先和独立手柄 | 多客户端持续观看、轮流输入、断线重连与撤权互不误伤；用实体手柄及真实驱动验收，不仅依赖模拟状态。 |
| 安装、更新与配置切换 | 已有完整包校验、空闲更新和逐配置主机资料 | 首次安装、取消授权、跨版本升级与切换配置均可恢复；保留已启用持久屏，不在活动串流中抢占服务。 |

## 下一步可补齐的能力

以下有明确的使用价值或当前缺口，尚未实现完整能力；需要逐项设计和验证。

| 方向 | 可完善的功能 | 需要解决的问题 |
|---|---|---|
| 受限网络 | TURN/TCP、TURN/TLS 回退 | 当前中转仅支持 UDP；需要在 UDP 被禁时建立可用路径，清楚提示延迟和拥塞代价。 |
| GPU 与平台 | 原生 NVENC 后端、减少 Linux CPU 读回、Linux HDR | NVIDIA 当前可经可用的系统硬件后端工作，原生 NVENC 是后端优化方向；Linux HDR 需连同采集、编码、颜色及呈现验证。 |
| 房主管理 | 限制远端点击本机会话中心 | 现有本机管理接口与会话权限边界不等于桌面输入隔离；需验证可行的平台机制，不能将普通置顶窗口称为受保护面板。 |
| 手柄与音频 | 震动回传、触摸板坐标、自适应扳机；麦克风与多声道 | 分开定义能力、授权与生命周期，验证实体设备和游戏；现有系统音频为立体声，不包含麦克风。 |
| Linux 共享 | 更完善的桌面授权恢复与主窗口 / 共享生命周期 | 当前退出桌面会话或明确退出 Eclipse 会停止共享；需尊重 Wayland 合成器的授权边界。 |
| 兼容接入 | 官方手机客户端互通验收、插件升级体验 | 原生协议不兼容 GameStream；UU 兼容插件的模拟协议检查不能代替官方手机客户端实测。 |

## 后续候选

这些是可评估的新功能，尚未进入交付承诺：

- **文件传输**：任务队列、取消与重试、目标位置选择及传输进度。
- **远程终端与端口转发**：独立能力授权、明确连接对象和会话结束行为。
- **休眠唤醒与无人值守体验**：先区分局域网唤醒、跨网可达、系统启动及桌面授权，避免把已安装后台服务等同于任何状态都能连接。

## 交付与验收原则

每项交付都应说明适用平台、真实后端、异常清理和已执行的验证。生成画面、隔离桌面、协议测试、编译及安装包核验只能证明各自范围；真实桌面、目标 GPU、实体外设、跨 NAT 和物理显示延迟需要对应实测。

性能目标参考 Sunshine + Moonlight，在相同条件下对比，不用单个 HUD 数值宣称全面更快。按独立改动提供可测试版本，再根据实际结果迭代。[产品方向与历史规划](vision.md) · [发布记录](releases/README.md)
