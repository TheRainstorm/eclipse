# 交付路线图

产品方向与技术取舍见[产品远景](vision.md)。此处仅跟踪阶段和验收；具体已发布能力以[发布说明](releases.md)为准。

| 阶段 | 当前状态 | 下一项交付与验收 |
|---|---|---|
| uu-client 日常兼容客户端 | 已可用，持续完善 | 首次使用、设备列表、错误反馈、升级、声音/输入/多屏稳定性；真实Windows与Linux路径闭环 |
| 原生局域网最小闭环 | 已发布到0.9 | 固定证书配对、加密音视频、显式键鼠许可与双方许可的文本剪贴板 |
| 0.6日常体验完善 | 已发布，两端安装验证通过 | 收藏/最近使用、异常配置保护与恢复、真实构建信息、跨平台色彩和Linux窗口退出回归；完整CI与安装验证 |
| Eclipse LAN 设备发现与配对 | 开发分支已接入，跨机器验收待完成 | IPv4发现、手动地址、主机确认、固定身份与撤销授权；设备页无需第三方账号，旧发布包仍走邀请文件 |
| Eclipse 单控体验 | 开发分支已接入切屏和门户 | 共享权限、门户授权与切屏实际桌面验收；运行中画质重协商待完善，不改主机既有布局 |
| 0.7 恢复与Linux原生硬件编码 | 已发布，完成长稳与双平台CI | SRTP回绕、读取生命周期、VA-API选择/回退、AltGr、共享地址与私有诊断；完整包交付 |
| 0.8 Linux硬件互通与观测 | 已发布，双平台CI及原包核验通过 | 有效NACK补包与重放记录、BGRA转换加速、SPS约束与零重排、尾部填充、停图FPS归零及调试不再隐式保存画面 |
| 0.9 客户端低延迟呈现 | 已发布，双平台CI及硬解重复对照通过 | GPU平面转换、Windows读回缓冲复用、低延迟接口、500ms统计；保留VSync，记录解码与渲染的真实范围 |
| GPU媒体管线 | Linux VA-API、Windows MFT 已有硬编；开发分支新增 Intel VPL | 验证 HEVC / AV1 的实际 GPU 互通与性能，减少 CPU 转换和上传；按平台测量端到端表现 |
| 高画质与恢复 | 开发分支已接入 H.265 / AV1 与 CBR / VBR | 目标 GPU 和驱动验收；HDR、自动码率与视频 FEC 待实现，需发送端和接收端共同验证 |
| 自托管公网连接 | 开发分支已接入自有信令、STUN、逐设备授权和路径详情 | 不同 NAT 的实际直连验收；STUN 无法保证任意网络打洞，自有 TURN 尚未实现 |
| 多控制端与扩展设备 | 开发分支已接入最多四会话、独占输入交接、手柄与运动传感器 | 实体手柄、UHID / ViGEmBus 驱动与实际多设备验收；UU 并发还受服务侧策略限制 |

先完成当前阶段的退出清理、错误提示、测试与安装交付，再扩展下一阶段。暂不为未实现功能显示可用入口，不将实验路径标成完整服务端；原生模式也不代表已兼容Sunshine / GameStream。

开发分支上述能力尚未作为新的版本标签发布。生成媒体、隔离门户与虚拟手柄测试用于验证协议和生命周期，不等同于真实桌面、目标 GPU、物理手柄或跨 NAT 验收；各功能文档记录其具体边界。
