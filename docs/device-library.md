# 收藏与最近使用（0.5之后的开发版）

设备标题旁的星标用于收藏或取消收藏，左侧星标提示已收藏。通过“全部设备”“最近使用”“收藏设备”切换列表，搜索同时匹配设备名称与设备ID。筛选改变后详情区跟随可见设备，不保留隐藏设备作为连接目标。

“最近使用”记录成功打开或激活过串流窗口的设备，最多20台；它表示使用记录，不保证当次网络连接已经成功。收藏和最近使用只显示当前账号设备列表中仍存在的设备，不恢复已解绑设备或上一账号的名称。

列表按账号在本地保存，只记录设备ID，不保存账号令牌、设备名称、壁纸或邀请文件。能确定账号标识时，重新登录仍沿用该账号记录；缺少账号标识时按当前登录态隔离，避免串到其它账号。不会把这些偏好上传服务端。

窗口高度较小时使用标题处的下拉筛选，隐藏装饰卡片与底部导航，为设备列表留出空间。悬停可查看完整设备名。

配置损坏、版本不支持或无法保存时会显示提示；损坏原文件不被新操作覆盖，本次仍可临时收藏。配置与其它偏好同处本地用户数据目录，属于个人资料，不应上传到issue、源码或安装包。Unix新文件权限为600，Windows沿用用户目录权限。
