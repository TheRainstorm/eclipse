# 客户端快捷键

在“应用设置 → 快捷键”中点击现有绑定并按下新组合。`＋` 增加绑定，`×` 移除，单项“默认”恢复原组合。每项最多三个绑定，支持 Ctrl、Alt、Shift、Win/Super 与普通键；录入中按 Esc 取消。更改先保留在草稿中，保存并应用后生效。

快捷键属于本机应用，全部串流窗口共用；保存后会同步到已打开的新版窗口，设备命名配置不覆盖它们。常用动作默认采用 Ctrl+Alt+Shift；全屏导航使用 Ctrl+Alt+方向键。显式自定义组合和禁用状态保持不变，单项“默认”可恢复对应默认值。菜单提示取自当前实际绑定。

| 操作 | 默认组合 |
|---|---|
| HUD | Ctrl+Alt+Shift+S |
| 悬浮菜单 | Ctrl+Alt+Shift+H |
| 静音 | Ctrl+Alt+Shift+M |
| 全屏 | Ctrl+Alt+Shift+F 或 Ctrl+Alt+Shift+X |
| 结束串流 | Ctrl+Alt+Shift+Q |
| 释放 / 恢复控制 | Ctrl+Alt+Shift+Z |
| 桌面 / 游戏鼠标 | Ctrl+Alt+Shift+P |
| 光标显示 | Ctrl+Alt+Shift+C |
| 嵌套快捷键透传 | Ctrl+Alt+Shift+F12 |
| 上一个 / 下一个远端屏幕（仅全屏） | Ctrl+Alt+Up / Down |
| 上一台 / 下一台串流电脑（仅全屏） | Ctrl+Alt+Left / Right |

全屏导航按当前窗口中设备组和屏幕标签的显示顺序循环，保留各电脑当前选择的屏幕；不会跳到其它独立窗口。窗口模式下，这四项绑定继续交给远端。多电脑全屏时，设备标签栏移到顶部才显示，以浮层覆盖画面，离开后隐藏，不占用固定画面高度。

重复组合会标红并指出对应操作；冲突不能保存应用。Shift 和 Win/Super 参与精确匹配，不会与缺少这些修饰键的组合混同。Windows 的 Ctrl+Alt+Delete 属于安全桌面，不能配置为客户端命令。可能与系统冲突的组合显示警告；“内部无冲突”仅表示本软件内不重复，无法保证其它软件或桌面环境不抢占。

快捷键仅在串流前台处理，不在后台注册全局快捷键。录入时暂停客户端命令匹配，避免录入“结束串流”组合时关闭连接。更改绑定会释放旧输入状态；按住组合时变更配置，需先松开修饰键再使用新组合。一次按下只触发一次，抬起仍属于原接收者。

嵌套模式按操作身份决定归属：其它客户端命令交给远端，只有“嵌套快捷键透传”的当前绑定始终在本机处理，必须至少保留一个，便于切回。改变绑定后不再固定保留 F12。右 Alt / AltGr 保留给远端文本输入，不触发本机命令。系统键的全屏捕获、失焦释放和主机输入授权继续遵守原规则。
