# 客户端快捷键

在“应用设置 → 快捷键”中点击现有绑定并按下新组合。`＋` 增加绑定，`×` 移除，单项“默认”恢复原组合。每项最多三个绑定，支持 Ctrl、Alt、Shift、Win/Super 与普通键；录入中按 Esc 取消。更改先保留在草稿中，保存并应用后生效。

快捷键属于本机应用，全部串流窗口共用；保存后会同步到已打开的新版窗口，设备命名配置不覆盖它们。常用动作默认采用 Ctrl+Alt；全屏导航使用 Ctrl+Alt+方向键。显式自定义组合和禁用状态保持不变，单项“默认”可恢复对应默认值。菜单提示取自当前实际绑定。

| 操作 | 默认组合 |
|---|---|
| HUD | Ctrl+Alt+S |
| 悬浮菜单 | Ctrl+Alt+H |
| 静音 | Ctrl+Alt+M |
| 垂直同步 | Ctrl+Alt+V |
| 全屏 | Ctrl+Alt+F 或 Ctrl+Alt+X |
| 结束串流 | Ctrl+Alt+Q |
| 释放 / 恢复控制 | Ctrl+Alt+Z |
| 桌面 / 游戏鼠标 | Ctrl+Alt+P |
| 光标显示 | Ctrl+Alt+C |
| 嵌套快捷键透传 | Ctrl+Alt+F12 |
| 返回本机 / 恢复串流 | Ctrl+Alt+D |
| 隐藏 / 恢复所有 Eclipse 窗口 | Ctrl+Alt+B |
| 上一个 / 下一个远端屏幕（仅全屏） | Ctrl+Alt+Left / Right |
| 上一台 / 下一台串流电脑（仅全屏） | Ctrl+Alt+Up / Down |

Ctrl+Alt+D 在 Windows 注册为进程级全局热键：隐藏全部串流窗口后仍可恢复，连接、HUD 历史与窗口几何保留；该命令在嵌套透传模式下仍由本机处理。全局热键注册失败时客户端拒绝隐藏窗口并提示占用原因，避免无法恢复。

垂直同步快捷键即时切换当前串流窗口，菜单显示其当前实际绑定；它与菜单开关、设置页保存应用共用同一呈现请求和原有保存规则。按住不连续切换，松开修饰键后该字母的抬起仍由本机消费；嵌套透传开启时交给远端。设备命名配置仍通过原有保存配置操作更新。升级时若 Ctrl+Alt+V 已被旧自定义绑定占用，保留原绑定，新增的垂直同步命令先保持未绑定，可在快捷键设置中配置。

全屏导航按当前窗口中设备组和屏幕标签的显示顺序循环，保留各电脑当前选择的屏幕；不会跳到其它独立窗口。窗口模式下，这四项绑定继续交给远端。全屏时不显示顶部设备栏，也不会因鼠标移到顶部自动展开。鼠标切换可打开串流菜单，点击“设备与屏幕”；选择后关闭，不占用固定画面高度。

可以一直按住 Ctrl+Alt，反复点按方向键连续切换。切换期间本机命令继续响应，旧远端组合的重复和抬起仍归原窗口处理；其它远端输入等旧修饰键全部松开后恢复。更改快捷键绑定仍需先松开旧组合。

重复组合会标红并指出对应操作；冲突不能保存应用。Shift 和 Win/Super 参与精确匹配，不会与缺少这些修饰键的组合混同。Windows 的 Ctrl+Alt+Delete 属于安全桌面，不能配置为客户端命令。可能与系统冲突的组合显示警告；“内部无冲突”仅表示本软件内不重复，无法保证其它软件或桌面环境不抢占。

除返回本机和老板键外，客户端快捷键仅在串流前台处理。录入时暂停前台与全局命令，录入老板键或结束串流的组合也只修改草稿。更改绑定会释放旧输入状态；按住组合时变更配置，需先松开修饰键再使用新组合。一次按下只触发一次，抬起仍属于原接收者。

嵌套模式按操作身份决定归属：其它客户端命令交给远端，“嵌套快捷键透传”、返回本机和老板键的当前绑定始终在本机处理，必须至少保留一个，便于切回。改变绑定后不再固定保留 F12。右 Alt / AltGr 保留给远端文本输入，不触发本机命令。系统键的全屏捕获、失焦释放和主机输入授权继续遵守原规则。

Ctrl+Alt+B 统一隐藏或恢复本机所有串流窗口；Eclipse 主窗口、服务管理及悬浮会话中心保持原样。隐藏时保留原窗口、全屏、最大化和连接；再次按下恢复之前可见的串流窗口，原本隐藏的窗口保持隐藏。视频、声音和后台服务继续运行，远端长按输入在隐藏前释放。它与 Ctrl+Alt+D 的当前串流窗口控制独立。

主动恢复时，将上次使用的可见串流窗口带到前台；此前最小化的窗口保持最小化。恢复窗口不改变本机／远端输入归属，返回本机后仍保持本机输入。因全局快捷键失效等原因自动恢复窗口时不主动抢焦点；Windows 前台授权与 Wayland 激活仍由系统决定。

Windows 使用全局热键，Linux X11 使用桌面按键注册，Wayland 使用桌面 GlobalShortcuts 门户。系统不支持或组合被占用时不隐藏，避免丢失恢复入口。快捷键录入期间临时归还整条按键流；录入结束或录入进程退出后恢复注册。
