# 界面设计系统

Eclipse 的桌面界面使用 egui 0.29。主程序和扩展共用 `uu_plugin_sdk::theme`，颜色、控件状态和空间参数从这一个入口定义。暗色界面采用克制的蓝色强调，通过背景明度区分主底色、卡片和浮层；亮色界面使用同样的层级、几何和交互规则。

## 颜色与层级

| 语义 | 暗色 | 亮色 | 用途 |
| --- | --- | --- | --- |
| Base | `#11151C` | `#F5F8FC` | 页面底色 |
| Card | `#1B222D` | `#FFFFFF` | 内容分组 |
| Overlay | `#252F3D` | `#FAFCFF` | 菜单、弹窗 |
| Sidebar | `#171D27` | `#EFF5FD` | 导航 |
| 正文 | `#E8EDF5` | `#17253D` | 主要信息 |
| 次要文字 | `#A8B5C6` | `#53647C` | 说明、元数据 |
| 容器描边 | `#344152` | `#DDE6F2` | 轻量分组，不抢视觉焦点 |
| 控件描边 | `#788BA4` | `#8193AB` | 输入和按钮边界 |
| 强调文字 | `#8DB7FF` | `#2563EB` | 链接、选中标识 |
| 主操作背景 | `#2563EB` | `#2563EB` | 保存、连接等主要操作，配白字 |
| 成功 | `#62D5A2` | `#167049` | 在线、运行正常 |
| 警告 | `#F2C66D` | `#855200` | 需要关注的状态 |
| 危险 | `#FF8D9B` | `#B42336` | 错误、失败 |

正文与次要文字在三个背景层上均以至少 4.5:1 为检查目标；输入边框与控件底色至少 3:1。状态标签使用同色系浅底和文字，标签本身必须说明含义，不能仅以红绿区分。主操作的强调背景与强调文字分别定义，避免在暗色中用过亮的蓝底配白字。

## 控件规则

`Primary` 用于当前区域的核心操作；`Secondary` 用于常规操作；`Ghost` 用于取消、导航和轻量工具。普通 `ui.button` 遵循全局 Secondary 状态，主操作使用 `theme::primary_button`，轻量操作使用 `theme::ghost_button`。所有层级复用 egui 的焦点、键盘激活、可访问性和 `ui.add_enabled` 禁用规则。

| 状态 | Primary | Secondary | Ghost |
| --- | --- | --- | --- |
| 默认 | `#2563EB`、白字 | 控件底色与细描边 | 透明底色 |
| 悬停 | `#2A6BEE`、强调描边 | 明度提升、强调描边 | 明度提升 |
| 按下 / 键盘焦点 | `#1D4ED8`、强调描边 | 更深底色、1.5px 描边 | 更深底色、强调描边 |
| 禁用 | 中性色底、次要文字 | 中性色底、次要文字 | 中性色底、次要文字 |

禁用控件不能点击或展示可点击手势。图标按钮遵循同样的悬停、按下、选中和禁用优先级。反馈由输入状态直接驱动，不增加持续动画或后台重绘循环。

不要给主按钮直接调用 `egui::Button::fill`：这个 API 会覆盖所有交互状态的填充。公共按钮通过局部 Visuals 设置各态，内部仍由原生 egui Button 负责交互。公共卡片使用 `theme::card`，状态标签使用 `theme::pill` 和 `Tone::{Neutral,Info,Success,Warning,Danger}`。

## 几何、文字和间距

| 参数 | 取值 |
| --- | --- |
| 间距梯度 | 4 / 8 / 12 / 16 / 24px |
| 常规圆角 | 8px |
| 卡片内边距 | 16px |
| 按钮内边距 | 横向 12px、纵向 8px |
| 常规最小控件高度 | 32px；文字实际高度可使其更高 |
| 紧凑标题栏图标命中区 | 保留 30px，避免改变既有窗口控制布局 |
| 页标题 | 24px |
| 分组标题 | 16px |
| 正文 / 按钮 | 14px |
| 说明 / 元数据 / Pill | 12px |
| Pill 内边距 | 横向 8px、纵向 4px |

分组依靠背景层级和间距建立秩序；细描边补充轮廓。仅浮层可使用 egui 的窗口阴影，内容卡片不叠加大面积投影。已有图标保持共用的矢量路径，不因页面重新引入独立图标体系。

## 集成与验证

初始化调用 `theme::apply(ctx)`，为 Dark 和 Light 分别注册样式，不覆盖宿主的主题偏好。绘制时用 `theme::palette(ui.visuals())` 取得当前颜色，避免把亮色常量写入新的控件。旧兼容常量仅服务尚未迁移的自绘区域；页面迁移时应使用 Palette。主题只影响应用控件，不改变远端画面色彩、视频呈现或串流参数。

`cargo run -p uu-gui --example design_system_preview -- --x11-display :N --output PATH` 使用 launcher 创建且可证明所有权的 Xvfb，绘制生成的设备、设置和状态内容；不连接真实电脑、不读取桌面。`--light` 生成亮色对照，`--state hover` / `pressed` 注入自有窗口的按钮状态。颜色对比、主题切换、原生点击与禁用行为有定向测试；这些检查不能代替实体桌面的体验验收。

## 首次连接与画质选择

设备页空状态给出四步指引：在对方电脑开启服务、添加其地址、完成首次配对、开始串流。没有安全连接密码时提供设置入口，也可继续使用配对码或预授权公钥。设备卡片显示保存的连接地址、最近的在线检查状态和开始串流操作；在线检查不等于已获得连接授权。

画面页默认先展示画质偏好，详细参数在“高级设置”中调整。预设只修改当前设置草稿，仍通过原有保存流程生效：

| 偏好 | 输出尺寸上限 | 带宽设置 | 目标帧率 |
| --- | --- | --- | --- |
| 极速流畅 | 1920×1080 | 8 Mbps | 60，遵守连接上限 |
| 平衡 | 2560×1440 | 按实际尺寸和编码推荐 | 60，遵守连接上限 |
| 极致画质 | 保持远端尺寸 | 按实际尺寸和编码推荐 | 60，遵守连接上限 |

编码自动协商。输出尺寸上限保持画面比例；实际结果取决于远端能力和网络。高级修改后自动显示“自定义”，已有设备配置继续保存其原值。声音、输入和呈现偏好由原有设置独立管理。
