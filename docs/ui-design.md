# 桌面界面设计

主页、设置页、对话框、插件和串流菜单共用 SDK 的语义颜色与控件。可选配色为天蓝色、蓝和动森；天蓝色默认使用浅色外观，蓝和动森支持浅色、深色及跟随系统。切换到天蓝色不会丢失其它配色使用的深浅偏好。旧默认蓝设置迁移为天蓝色。

| 用途 | 颜色 |
|---|---|
| 天蓝色主操作、选中 | `#C9E8FA`，配深色文字 |
| 天蓝色页面背景、内容表面 | `#F4FAFF`、白色 |
| 天蓝色正文、次级文字 | `#24455C`、`#4E697D` |
| 动森页面、侧栏、正文 | `#F8F8F0`、`#F0E8D8`、`#794F27` |

默认正文 14 点、次级文字 12 点，使用本机中文字体；不在线下载字体。间距以 4/8 点为基础，常规按钮至少 32 点高；浮动菜单及右键菜单共用 13 点文字和 30 点选项行。动作行无需按钮边框；动森的标签和选择器使用独立控件样式。浅色主操作根据背景使用深色文字，焦点边框可见，错误同时显示文字与颜色。

Windows 服务卡片显示统一状态和简短版本；实际运行和安装构建放在版本悬停信息中。程序与已启用插件的更新在空闲时自动衔接，取消系统授权后保留待完成状态，不反复请求授权。“连接服务”只显示已启用插件的对应卡片，原始错误和路径折叠在诊断详情中。保存并重启没有连接时直接执行，有连接或数量未知时在当前页居中确认，取消保留草稿。

0.14 的主页统一为四个入口：设备列表、服务管理、UU 兼容和应用设置。顶部左侧显示 `Eclipse / 当前页面`，设备详情显示可返回的面包屑；顶部右侧是四个主页图标和窗口控制。设备根页使用连贯壁纸，设备详情、服务管理、UU 兼容和应用设置使用不透明蓝白表面。设备列表只呈现最后画面或稳定颜色占位、名称；单击连接，空白处右键添加，卡片右键管理详情、连接方式和客户端配置。

Windows 服务管理操作同一个后台主机，包含服务管理、输入、音频/视频、编码器、配对、连接服务和虚拟显示器标签。应用设置提供壁纸、软件自启动、设备发现等通用选项，界面支持即时中英文切换。兼容插件提供自己的设备与账号页面；设备画质与当前串流设置沿用画面、声音、键鼠和串流信息分类。

保存成功等短反馈绑定所属页面或标签并在约两秒后消失；运行状态、配对状态和会话直接读取真实状态，不重复绘制为成功消息；入口或保存错误保留在发生问题的控件附近。内容滚动时保留返回与保存入口，取消不保存草稿，切换页面不会恢复旧提示。

悬浮菜单的悬停、点击、拖动及失焦遵循同一状态规则：悬停展开后离开立即收起，点击交互后离开或窗口失焦两秒收起；编辑文本期间保留菜单键盘焦点。主菜单与子菜单间仅保留狭窄的移动通路，防止经过间隙时误收起，也不覆盖大块视频区域。

设置页或本地菜单获得交互时，由统一输入归属停止远端输入；退出、失焦及持有按键时切换仍沿用同一清理规则。界面美化不改变视频解码与呈现调度。

普通主窗口和串流窗口都接受系统的位置与 DPI 变化，移动时取消此前未完成的尺寸收敛和首帧适配；跨屏后不再按视频比例自动居中。首次布局、首次视频显示或明确打开设置页时才发起对应的尺寸调整。原生窗口 DPI 与当前 UI 帧比例不一致时，暂缓提交尺寸与位置，避免用旧比例换算新监视器坐标。Windows DPI 事件提供建议矩形，参见 [WM_DPICHANGED](https://learn.microsoft.com/en-us/windows/win32/hidpi/wm-dpichanged)。

串流菜单的显示器入口集中当前设备的显示源与虚拟屏操作，屏幕工具栏使用平面选中状态。HUD 与悬浮入口可见性均使用统一开关；自动剪贴板同步成功只更新计数，不常驻显示成功提示。没有实际功能的占位菜单不展示。

## 设备列表与壁纸

设备列表的右键菜单可隐藏或显示设备，并进入管理模式。管理模式支持多选删除及拖动排序；隐藏后可在空白区域右键恢复。设置中可分别调整设备图标和文字大小。

壁纸刷新策略为不刷新、每次打开和每隔指定小时刷新。收藏不限张数，每页20张，按收藏时间从新到旧显示；页码按旧到新分组，最大页优先，页码从大到小排列，增加新图不会整体改动旧页。

可以直接把标准图片文件放进程序目录的 `wallpapers/favorites`。首次扫描发现时间作为收藏时间，重复扫描保留原时间；重复内容只显示一项。图库自动检查目录变化，也可手动刷新。右键图片可删除收藏；使用旧版 `.image` 收藏时迁移为标准扩展名。

关于窗口直接显示精确到秒的构建时间，保留复制版本信息。新手教程只说明连接和配对，可以从设置重新打开。
