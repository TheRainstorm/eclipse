# 桌面界面设计

界面采用简洁的蓝白风格，主页、设置页、对话框和串流菜单共用 `uu-gui/src/theme.rs` 的颜色与控件状态。设计参考 [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 的 Minimalism & Swiss Style、通用桌面导航与错误反馈规则，按原生 egui 的布局和输入模型实现。

| 用途 | 颜色 |
|---|---|
| 主操作、选中、焦点 | `#2563EB` |
| 页面背景、内容表面 | `#F5F8FC`、白色 |
| 正文、次级文字 | `#17253D`、`#53647C` |
| 边框、浅蓝状态 | `#DDE6F2`、`#EAF2FF` |

默认正文 14 点、次级文字 12 点，使用本机中文字体；不在线下载字体。间距以 4/8 点为基础，常规按钮至少 32 点高；浮动菜单采用更紧凑的桌面指针布局。主操作蓝底白字，焦点边框可见，错误同时显示文字与颜色。

0.14 的主页统一为四个入口：设备列表、服务管理、UU 兼容和应用设置。顶部左侧显示 `Eclipse / 当前页面`，设备详情显示可返回的面包屑；顶部右侧是四个主页图标和窗口控制。设备根页使用连贯壁纸，设备详情、服务管理、UU 兼容和应用设置使用不透明蓝白表面。设备列表只呈现最后画面或稳定颜色占位、名称；单击连接，空白处右键添加，卡片右键管理详情、连接方式和客户端配置。

服务管理包含连接服务、输入、音频/视频和编码器四类标签，服务控制与会话集中在连接页。应用设置使用软件设置/关于双页签，只提供壁纸、软件自启动、设备发现等通用选项，界面当前为简体中文。UU 兼容直接进入原版设备界面，远程协助位于原版侧栏。设备配置与串流临时设置分别使用画面、声音、键鼠和串流信息分类，全局默认可从设备配置编辑器进入。

保存成功等短反馈绑定所属页面或标签并在约两秒后消失；运行状态、配对状态和会话直接读取真实状态，不重复绘制为成功消息；入口或保存错误保留在发生问题的控件附近。内容滚动时保留返回与保存入口，取消不保存草稿，切换页面不会恢复旧提示。

悬浮菜单的悬停、点击、拖动及失焦遵循同一状态规则：悬停展开后离开立即收起，点击交互后离开或窗口失焦两秒收起；编辑文本期间保留菜单键盘焦点。主菜单与子菜单间仅保留狭窄的移动通路，防止经过间隙时误收起，也不覆盖大块视频区域。

设置页或本地菜单获得交互时，由统一输入归属停止远端输入；退出、失焦及持有按键时切换仍沿用同一清理规则。界面美化不改变视频解码与呈现调度。
