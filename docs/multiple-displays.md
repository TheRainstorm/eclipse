# 多显示器独立窗口

Eclipse 原生串流可以为同一台远端电脑的不同显示器分别建立串流，每个窗口都有自己的全屏、HUD、画质和输入状态。可以把窗口拖到不同的本地显示器上，再分别全屏。

顶部主机名会激活该设备最近使用的显示视图，Ctrl+Alt 左右切机和设备选择器遵循同一规则。显示器标签使用“编号:名称”，完整名称可以悬停查看；新版 Windows 主机提供监视器友好名称及 HDR 状态。友好名称只影响显示文字，切屏与重连仍使用原始显示源标识。旧主机继续显示原有源名称。

连接远端电脑后，在显示器标签上右键选择“在独立窗口中打开”。全屏时，通过串流菜单中的“设备与屏幕”打开选择器，点击某块屏幕旁的“独立窗口”；也可以选择“所有屏幕独立打开”。已存在的固定源视图会被复用；普通主连接恰好显示该屏幕时，不会因打开独立视图而被移走。普通设备标签仍可移到独立窗口，移动标签不重建媒体连接。

同一窗口中的同一台电脑使用一个设备标签组，物理屏和临时虚拟屏显示在组内。不同屏幕仍有各自的连接、画质及租约，不会因归为一组而合并连接。标签较多时可横向滚动，悬停可查看完整名称。电脑名右键菜单中的“断开此会话”只结束该组当前活动的视图；屏幕标签右键操作属于该屏幕自己的连接。

右键卡片选择“移到独立窗口”，会固定这条连接当前显示的源并移动到新窗口；普通设备窗口即使只有一条连接也可以这样移动。在移出的卡片上右键选择“合并到原本窗口”，可把同一条连接移回；合并后仍可再次移出。这些窗口操作保留连接、画质和租约。

“+”在当前电脑的设备标签组内新增一个虚拟屏视图，由独立连接在开始采集前创建并选中自己的临时虚拟显示器。原屏幕连接保持原采集源。关闭新卡片时只结束它自己的串流并回收虚拟屏，原屏幕继续；把卡片移到独立窗口不会重建连接或转移租约。创建失败时原连接仍然保留，可关闭失败的卡片后重试。

独立新建临时屏需要两端更新，并授予控制端“管理服务和连接”权限。使用 Windows 后台共享时，也要更新实际后台程序并重新连接；只更新普通目录中的 GUI 不会更新后台能力。

新卡片在虚拟屏创建、目录确认和对应画面到达之前保持画面及输入门禁，不会暂时显示或操作原物理屏。临时布局仅保存在内存，不覆盖原设备的显示器选择。

独立屏幕视图在目标屏幕确认并收到对应画面后才显示视频、开放输入。它只显示绑定的那一枚源标签，不在本连接切到其它屏幕；合并回原窗口后仍保持这个绑定。普通设备主连接继续提供多个显示源的选择。“所有屏幕独立打开”保留当前屏幕在原窗口，其余屏幕打开独立视图；合并会将同一条连接移回原窗口并归入同一电脑的标签组。目标屏幕消失或名称不唯一时，视图会提示错误，不会悄悄回到另一块屏幕。显式打开已有屏幕的布局记录与普通设备窗口分开保存，临时虚拟屏不保存布局。

新增屏幕窗口默认静音，避免同一台电脑的系统声音重复播放；可在各自声音菜单里开启。键鼠控制跟随当前获得焦点的串流窗口，同一远端主机仍只允许一个输入所有者。关闭一个窗口只结束其中的连接，其它窗口继续串流。

每块独立屏幕占用一个主机会话以及一套采集、编码和解码资源。原生共享不对已认证媒体会话设置统一的固定数量上限，实际可同时运行的屏幕数取决于驱动容量、两端硬件及各窗口画质。认证前握手和连接提供方仍有各自的资源限制；自建信令版本 1 仍为单会话，版本 2 支持按会话路由；旧服务版本可能仍有四会话限制，需要同步更新。远端需提供原生显示器目录；独立插件协议不自动获得此能力。

右键“+”可选择命名的虚拟显示器规格；左键使用默认规格。在“软件设置 → 虚拟显示器规格”中可设置默认项、新增或编辑名称、分辨率、刷新率和 HDR。规格只决定之后新建屏幕的参数，不会修改已有屏幕。
