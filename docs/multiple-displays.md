# 多显示器独立窗口

Eclipse 原生串流可以为同一台远端电脑的不同显示器分别建立串流，每个窗口都有自己的全屏、HUD、画质和输入状态。可以把窗口拖到不同的本地显示器上，再分别全屏。

连接远端电脑后，在显示器标签上右键选择“在独立窗口中打开”。全屏时，通过串流菜单中的“设备与屏幕”打开选择器，点击某块屏幕旁的“独立窗口”；也可以选择“所有屏幕独立打开”。已打开并正在显示相同屏幕的窗口会被复用。普通设备标签仍可移到独立窗口，移动标签不重建媒体连接。

独立窗口在目标屏幕确认并收到对应画面后才显示视频、开放输入。目标屏幕消失或名称不唯一时，窗口会提示重新选择，不会悄悄回到另一块屏幕。首次选择完成后，仍可在该窗口正常切屏。独立窗口的显示布局记录与普通设备窗口分开保存。

新增屏幕窗口默认静音，避免同一台电脑的系统声音重复播放；可在各自声音菜单里开启。键鼠控制跟随当前获得焦点的串流窗口，同一远端主机仍只允许一个输入所有者。关闭一个窗口只结束其中的连接，其它窗口继续串流。

每块独立屏幕占用一个主机会话以及一套采集、编码和解码资源。主机现有的四个并发会话上限仍适用，并包含其它控制端连接。远端需提供原生显示器目录；独立插件协议不自动获得此能力。多屏的实际帧率取决于两端硬件和各窗口画质。
