# 多显示器与串流窗口

同一台远端电脑的显示器使用一个标签组。连接后，窗口列出最初可用的所有显示器，只连接上次确认选择的屏幕；其它屏签在首次选中时连接。每条已打开的串流保留自己的画质、全屏、HUD 和输入状态。屏签名称按文字宽度显示，较长时可横向滚动或悬停查看完整名称。

Windows 显示源按远端 `DISPLAY` 编号显示，例如 `DISPLAY2` 的友好名称为 `27E1` 时显示为 `2:27E1`。初始目录按数字顺序排列；拖动标签只改变排列，不重新编号。友好名称、显示编号与串流控制 ID 各自独立，连接仍使用完整源标识。

窗口拥有自己的屏签。将某块屏幕移到独立窗口后，原窗口就不再拥有它，Ctrl+Alt+Left / Right 只循环当前窗口、当前电脑的屏签。Ctrl+Alt+Up / Down 切换当前窗口中的电脑，点击电脑名则返回该电脑最近使用的视图。命令可以在客户端快捷键设置中修改，已有自定义绑定保留。

屏幕右键的“移到独立窗口”移动该屏签及其已有连接，保持控制器、媒体连接和虚拟显示器租约；尚未连接的屏签移动后再连接。“合并到原本窗口”选择当前窗口以外、创建最早且仍存活的串流窗口。电脑名右键的合并操作移动当前窗口中该电脑的全部屏签。已经关闭的窗口不会因合并被重新创建。

Windows 也可把屏签或电脑标签拖到另一个串流窗口合并。跨窗口放置使用真实窗口的物理坐标，检查目标确实属于本工作区；其它桌面环境若不提供全局指针坐标，可使用明确的合并菜单。

右键“+”只列活动显示器，分为“已有显示器”、Eclipse 创建的持久虚拟显示器和临时虚拟显示器。物理屏和其它软件创建的虚拟屏都属于已有显示器。每行可选择当前窗口或独立窗口。已由任一窗口拥有的屏幕显示为不可选，包括尚未连接的屏签。关闭某块屏签后，可从这里重新打开。

悬浮菜单的“显示器”集中列出当前设备的这些显示源，可切换本窗口屏签、创建虚拟显示器或移除空闲的手动虚拟显示器。其它窗口拥有的屏幕不可重复打开，连接临时屏仍由所属连接回收。

左键“+”优先在当前窗口打开尚未被拥有的已有显示器，其次选择 Eclipse 已创建的活动虚拟显示器；都没有时创建临时虚拟显示器。右键还可明确新建临时屏或持久屏。新虚拟屏由独立连接在开始采集前创建和选中，原屏幕保持原采集源。创建或源确认失败时保留错误，不自动重复创建。

| 操作 | 退出范围 |
| --- | --- |
| Ctrl+Alt+Q | 当前窗口、当前电脑的全部屏签 |
| 屏幕右键“断开此会话” | 该屏签及其连接 |
| 电脑名右键“断开此会话” | 当前窗口中该电脑的全部屏签 |
| 窗口关闭按钮 | 当前窗口的全部电脑和屏签；包含多台电脑时先确认 |

关闭操作立即移除屏签，连接仍由原所有者完成清理；不会先返回此前隐藏的旧屏幕再要求退出一次。其它窗口继续串流。临时虚拟显示器随所属连接断开回收，持久显示器保留。移动或合并窗口不会改变显示器的临时、持久属性。

关闭或移出当前屏签后，返回当前窗口中最近访问且仍存在的屏签；没有访问历史时才选择第一块屏幕。关闭非当前页不会切换当前画面，屏签排列顺序也不随访问历史改变。

独立视图在目标屏幕确认并收到对应画面后才显示视频、开放输入。显示源消失或名称不唯一时保持门禁，不回退到另一块屏幕。友好名称只影响显示文字，连接和重连仍使用原始源标识。仅提供人工选屏的桌面门户、独立插件协议等入口，仍受各自平台授权和协议能力限制。

同一窗口中同一电脑的屏签共享音量和静音设置，并只播放一条音频。切换显示器时保留已在播放的音频源；该连接退出或失去音频能力时才改由另一条可用连接播放。新建独立显示窗口默认静音，可在自己的声音菜单开启；不同窗口的声音设置相互独立，合并后采用目标窗口的设置。键鼠控制跟随当前获得焦点的窗口，同一远端主机仍只允许一个输入所有者。

输入归属与视频绘制分别管理：失焦释放键鼠，不暂停其它已显示窗口的画面。Windows 按窗口合并普通重绘请求，通过异步原生通知执行绘制，可见窗口和隐藏协调窗口遵循同一规则。绘制期间因原生消息重入而产生的请求会缓冲去重，避免在重绘通知的生产路径内连续执行图形工作；硬件输入优先于投递的帧通知处理，不增加固定帧率限制。系统曝光和缩放仍使用必要的原生绘制路径。消息优先级依据 Microsoft 的 [PeekMessage 说明](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-peekmessagew)。`repaint_probe` 需要明确指定 `--owned-visible-windows`，仅使用自有生成窗口验证 GPU 绘制的空闲收敛和持续输入下的更新，不采集用户桌面或移动真实鼠标；实际多屏串流仍需在目标机器验证。

独立显示视图需要远端原生显示目录，创建和管理虚拟显示器还需“管理服务和连接”权限及更新后的主机服务。Windows 主机对同一物理屏幕的多个客户端共用一套采集所有者，但每个客户端仍占用独立编码、传输和解码资源；不同屏幕通常各有采集所有者。可并行运行的数量取决于端口、驱动和两端硬件。服务端会话面板可单独切换某个客户端采集的显示器并修改该会话画质；客户端不能操作该面板。自建信令版本 1 仍为单会话，版本 2 支持按会话路由。

虚拟屏默认规格在“软件设置 → 虚拟显示器规格”中维护，名称、分辨率、刷新率和 HDR 只决定之后新建屏幕的参数。主机创建上限及持久显示器由统一服务管理，详见[虚拟显示器](virtual-displays.md)。
