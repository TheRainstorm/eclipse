# 数据目录、便携模式与迁移

Windows 默认采用便携模式：解压完整包，双击 `eclipse.exe` 即可运行，首次启动自动创建程序旁的 `eclipse-data`。Linux 继续使用用户数据目录，可按需在设置中迁移到独立目录。以下描述当前开发分支；旧发布包以对应版本说明为准。

## 默认位置

| 内容 | Windows | Linux |
|---|---|---|
| 设置、设备、配对身份、插件数据 | `程序目录/eclipse-data/data` | `~/.local/share/eclipse` |
| 日志与运行状态 | `程序目录/eclipse-data/state` | `~/.local/state/eclipse` |
| Windows 服务运行资料 | `%ProgramData%/EclipseRemoteHost/profiles/<服务存储标识>/` | 不适用 |

Windows 无需手工创建便携标记或执行安装脚本。程序目录需要可写；无法创建数据时显示错误，不悄悄改用另一份配置。Linux 尊重 `XDG_DATA_HOME`、`XDG_STATE_HOME` 设置。

```text
Eclipse/
├── eclipse.exe             # Linux 为 eclipse
├── eclipse-cli.exe
├── plugins/
│   └── wallpaper-collects/  # 完整包自带，默认关闭
└── eclipse-data/            # Windows 首次运行自动创建
    ├── data/
    │   ├── gui-settings.json
    │   ├── device-trust/
    │   ├── plugins/
    │   └── server/          # 此配置的主机资料副本
    └── state/
```

## 在设置中更换目录

1. 打开“应用设置 → 常规 → 配置存储”。
2. 输入或选择新的数据根目录；迁移后里面包含 `data` 和 `state`，不要直接选其中的 `data` 子目录。
3. 点击“保存、迁移并重启”。程序保存当前设置，退出后迁移，完成后重新打开。

请先退出使用这份配置的其它串流窗口和管理进程；迁移不会替你关闭它们。目的地须为空或尚未创建，不把两套设备身份、插件账号和服务配置合并。失败会保留原配置，显示原因；旧目录在成功后也保留为备份，确认无误后可自行清理。

迁移保留设备身份、配对、插件偏好、主机配置和日志，不复制仍属于进程的锁、临时连接凭据和运行端点。Windows 已安装的本配置服务需要在空闲时切换数据绑定，按系统提示授权；后台仍是旧版本时，先完成服务更新。原来运行的服务恢复运行，原来停止的仍保持停止。持久虚拟显示器保留原设备，不因更换数据目录重新创建。

Windows 在程序旁的 `eclipse-profile.json` 记录自选目录；升级时同时保留此文件。选择“恢复默认目录”可将数据迁回程序旁的 `eclipse-data`，默认目录也须为空，同样需要迁移并重启。Linux 的自选位置记录在 `$XDG_CONFIG_HOME/eclipse/profile.json`（未设置时为 `~/.config/eclipse/profile.json`），更新安装包不改变该选择。

设置中的迁移不会移动程序文件和插件动态库，它们仍在软件目录。`wallpapers/favorites` 和 `wallpapers/cache` 也在程序目录，复制或备份整个应用时一并保留。

## 复制程序与独立试用

采用默认 Windows 目录时，退出此配置的所有窗口和托盘，并停止所属主机服务，再复制整个程序目录，即可携带客户端及服务端配置。Linux 也可显式使用程序旁的 eclipse-data 创建独立便携配置。

使用自选目录时，复制程序目录不会自动带走外部数据：同时备份所选的数据根目录，或先在设置中迁回默认便携目录。连接服务在配置内保存的凭据使用相对位置；自己选择的外部证书、令牌文件还需单独保留。

要体验首次使用，Windows 将完整包解压到新的可写目录即可；不要复制已有的 eclipse-data 或 eclipse-profile.json。Linux 可在新解压目录创建空的 eclipse-data，再运行该目录的程序。只想重看教程，在“应用设置 → 常规”点击“打开新手教程”，无需移动数据。

复制出的身份仍代表原设备。迁到另一台电脑并希望成为新的独立设备时，应使用空白配置重新配对。

## Windows 主机服务

每份客户端配置的 data/server 保存独立的主机身份、配对密码、授权、连接服务与虚拟显示器设置。客户端和主机使用各自的身份。

Windows 同时运行一个 Eclipse 主机服务。启用某份配置时，服务使用 ProgramData 内的受保护运行资料，并将变更同步回所属的 data/server。设置内迁移会保留服务存储身份，调整回存位置；用户配置移动不改变已有持久虚拟屏的归属。Windows 服务注册、驱动安装与受保护运行日志属于当前电脑，不能只靠复制目录迁到其它电脑。

另一份程序配置不会自动接管当前服务；需要在“服务管理”中切换，有串流时先断开。在另一台电脑上使用被控功能时，仍需启用当地服务、检查防火墙和安装所需驱动。[后台服务说明](windows-background-service.md)

## Linux 主窗口与共享

Linux 的共享主机运行在登录桌面会话中。“关闭主窗口时最小化到系统托盘”开启且桌面托盘可用时，关闭主页只隐藏窗口，共享继续。明确选择“退出 Eclipse 并停止共享”或退出桌面会话才会停止，它不等同于 Windows 系统服务。

Wayland 的采集和输入遵循门户或合成器授权。更换数据目录不会绕过授权，重启后按桌面要求重新选择共享屏幕。[Linux 说明](linux-client.md)

## 高级启动方式

ECLIPSE_PROFILE_DIR 可显式指定绝对数据根目录，内部仍为 data 与 state。它的优先级高于设置保存的位置，其次采用平台默认位置；显式启动覆盖不修改其它配置。在有该变量的启动环境里修改目录后，后续启动也需要更新或移除此覆盖。

Windows 默认目录为程序旁 eclipse-data。Linux 未指定自选位置时，仍可通过程序旁已有的 eclipse-data 启用便携模式，否则使用 XDG 用户目录。新建的 Windows 便携目录不自动导入历史用户配置。

收藏目录可以手工加入 PNG、JPEG、WebP、BMP 或 ICO；首次扫描时间视为收藏时间。壁纸缓存按最近使用最多保留 100 张，收藏不参与淘汰；启动先显示上一张缓存，再按刷新策略更新。
