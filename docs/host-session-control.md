# 会话中心与共享游戏厅

Windows 托盘右键选择“悬浮会话中心”，或从“服务管理”打开同名入口。面板置顶显示当前配置所属主机的连接；关闭面板不停止主机、不结束串流，也不改变共享模式。

每个会话可以分别开启或关闭键盘、鼠标、手柄，选择采集显示器、提交码率和帧率、断开连接。设备的长期授权是会话权限上限；收回会话输入会释放按住状态，切屏或重建编码器后保持当前会话授权。会话结束后不把这些临时调整保存为设备长期权限。

开启“共享游戏厅”后，新加入的会话默认仅观看，没有键盘、鼠标、手柄输入和剪贴板同步。房主可逐项放行输入权限。已有会话保留当前输入授权；“全部仅观看”会收回所有当前会话的输入，包括仍在准备中的连接。游戏厅模式随当前主机配置保存，服务重启后继续生效。

游戏厅开启时，运行中的画质与显示器由房主面板控制；普通模式允许客户端调整自己会话的画质和显示器。网络客户端不能直接调用房主的会话管理写接口。

Windows 默认开启“本机键鼠优先”：本机真实键盘或鼠标活动会暂停远程键鼠并释放远程长按。默认在本机空闲3秒后自动恢复，按住本机按键或鼠标按钮时继续暂停；可取消自动恢复，改为房主手动恢复。远程注入的事件不会延长本机优先时间，暂停期间的输入不会在恢复后重放。面板还提供随时暂停与恢复远程键鼠的按钮。

多个获准会话都可以发送键鼠输入。实际操作的一端暂时拥有键鼠；停止操作500毫秒且没有按住按键或鼠标按钮后，另一端可自然接手，无需断开或重新授权。持续移动、打字、拖动或长按期间保持当前归属，其他端的竞争输入直接丢弃，不在交接后重放。失焦或主动释放控制时立即交还。

本机键鼠优先和手动暂停不撤销手柄权限、不复位正在使用的虚拟手柄。多个获准会话可以各自使用手柄，键鼠交接不重置手柄。实际手柄数量受主机驱动和游戏支持限制。Linux 可手动暂停远程键鼠，当前没有通用的本机物理输入检测。

该面板是普通桌面窗口，没有单独的安全桌面隔离；允许键鼠控制的远端仍可能操作主机桌面上的界面。
