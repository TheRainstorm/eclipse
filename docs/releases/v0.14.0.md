# v0.14.0：统一四主页、集中服务管理与 AV1 解码

- 主页面只显示壁纸与设备的最后画面缩略图、名称。单击设备连接，空白处右键添加；设备右键提供详情、连接方式、配置选择和编辑。每台设备可保存多个客户端配置，编辑采用画面、声音、输入和串流信息标签。
- 顶部统一为设备列表、服务管理、UU 兼容和应用设置四个主页入口，左侧显示 `Eclipse / 当前页面`，设备详情通过面包屑返回。设备根页壁纸覆盖整窗，详情、服务、设置和 UU 页面使用不透明蓝白表面。
- 服务管理以连接服务、输入、音频/视频和编码器标签组织；连接页集中启动/停止、随软件启动服务、新设备配对和当前会话。应用设置使用“软件设置 / 关于”页签，保留壁纸、设备发现、软件自启动等通用选项，界面目前为简体中文。UU 兼容直接进入原版设备界面，远程协助位于原版侧栏。
- 保存成功等短反馈绑定所属页面或标签并自动消失；运行状态、配对状态与会话直接读取真实状态，入口和保存错误保留在对应操作区域，不再跨页重复显示。
- 壁纸直接显示在设备卡片背后，网络图片每日缓存；加载或失败时提供内置蓝色背景。修复此前遮罩过白、图片几乎不可见的问题。
- 默认 TCP 服务与 UDP 发现端口改为 **48998 / 48999**，避开原 4799x 范围。旧配置中的原默认监听值一次迁移，自定义端口保留。历史远端地址按对端实际端口使用；对端未升级时不会擅自改写其地址。
- UU 显示名自动使用“电脑名-Eclipse”，与原生共享名称独立。主动登录和更新资料时刷新真实系统与硬件信息，保持原有 UU 编号。已有有效登录态先同步名称再生成二维码；未认证的旧设备可能仍在首次确认页显示旧名，确认后更新。
- Windows AV1 增加经过真实 I/P 解码验证的 Media Foundation D3D11 后端，保留 Intel VPL 回退。VPL 按驱动请求的表面几何分配内存，保留可见裁剪与边界校验。连接建立后没有首帧会明确超时，诊断记录解码能力失败原因。
- 编码器支持显式选择 Intel、NVIDIA、AMD，约束实际驱动且不静默改用其它厂商或软件。改善 Intel 低功耗编码选择、CBR 动态码率缓冲参数，并减少像素转换与输入缓冲复制。本版也包含此前 0.13 开发分支的设备多配置、原生画质协商与最后画面保存。

## 升级说明与边界

- 升级保留账号、原生授权和配置。关闭旧主页、串流窗口后重新打开，新设置才作用于新窗口。设备簿升级到 v4，首次修改时备份旧 v2/v3 配置；旧程序不支持 v4，回退应恢复对应备份。
- Intel HEVC / AV1 与 VBR 需要适配 GPU 的 VPL 运行时。当前 NVIDIA / AMD 指定后端支持 H.264 CBR，尚未接入 NVENC / AMF 专有参数和这些厂商的 HEVC / AV1 编码；不要把 AV1 硬解支持等同于 AV1 硬编支持。
- 原生目前最高 4K60；部分硬编路径仍有 CPU 转换或上传，不承诺所有 GPU 都能跑满。生成媒体、状态回归不代替真实桌面、手机扫码、实体手柄与跨 NAT 验收。
