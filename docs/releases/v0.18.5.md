# v0.18.5：Wayland 连接等待与取消修复

- 原生客户端按实际连接阶段显示进度：被控端准备画面、媒体连接、等待首帧、已连接。设备验证后等待系统选屏时，不再一直显示“正在验证并连接设备”。
- 取消连接时，显式关闭尚未完成的屏幕选择请求；门户初始化和屏幕授权共用可取消的准备期限，避免初始化阶段无限等待。

Wayland 被控端仍需完成系统要求的屏幕选择。若连接停在等待共享屏幕，请在被控端的系统选择器中选择屏幕；本版不提供免授权的无人值守访问。门户后端自身阻塞时，取消界面可能仍需在被控端关闭。

包含 [v0.18.4](v0.18.4.md) 的 Windows 首连及设备卡片修复。连接进度更新需更新客户端，选屏请求清理需更新 Linux 被控端；退出并重新打开主程序后生效。
