# v0.19.2

更新 HUD 与光标，并修复视频正常但控制暂停后无法通过画面恢复键鼠的问题。

- HUD 默认档位为 Compact：青绿色文字与窄幅半透明黑底。显示分辨率@FPS、编码、聚合 recv/dec/rnd FPS、RTT ±、原始 Loss、码率、enc/dec/rnd 和预估延迟。菜单提供 Compact / Detailed，悬停展示分组诊断，全英文标签。
- 主栏 Loss 在 FEC / RTX 修复前统计，成功修复也能看到原始缺包。修复后的剩余损失保留在详情；详情整理 NACK、RTX、FEC 和输入反馈。[口径说明](../hud.md)。
- 默认仅远端光标，保留“仅远端 / 本地和远端”两种模式；缺少远端光标能力时保留本地可见回退。旧配置迁移保持用户已选的双光标模式。
- 点击串流画面可以在尚未授予控制权时重新申请；暂停提示增加“恢复控制”。临时输入队列故障释放已按下的键鼠并保留控制请求，避免视频继续但输入永久暂停。

本地 release 核心 344、加密自环 2、GUI 156 项检查通过；生产 HUD 模块在隔离 Xvfb 完成实际渲染检查。外观和真实设备键鼠恢复效果仍需实机验收。预估延迟是已测阶段均值之和，包含 RTT/2 的对称链路假设，不是实测输入到显示延迟；缺少阶段只显示已知小计。

本版不改变 PyroWave 的实验性限制，既有高码率丢包问题仍待定位。更新控制端后重开旧窗口使用新版界面和恢复逻辑。
