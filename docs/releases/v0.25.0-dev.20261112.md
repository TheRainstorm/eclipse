# Eclipse 0.25.0-dev.20261112

本开发迭代以被控端为中心，按提交编号交付完整测试包，等待用户实机验收；不创建正式标签或 Release，也不递增 workspace 正式版本。

## 服务端会话面板

- “服务管理 → 会话”按每个正在连接的客户端显示键盘、鼠标、手柄开关、当前显示器、帧率和码率。
- 设备长期授权是输入权限上限；会话面板只能在上限内开启或缩减当前会话权限。缩减会立即释放已持有的键、鼠标按钮和虚拟手柄，重新开启不需要客户端重连。
- 会话面板可切换该客户端采集的显示器，并提交该会话的帧率、码率和 HDR 相关运行时画质。
- 客户端不能修改服务端管理面板、其它会话或主机配置。网络管理通道只接受只读状态查询；本机 GUI 和受保护服务管理入口拥有修改权。
- 客户端运行中的画质、显示器和主机配置请求会被拒绝；首次连接仍可提交初始画面偏好。客户端菜单在主机声明服务端管理后显示只读提示，不再提供会失败的画质和切屏操作。

## 多客户端同屏

Windows 同一物理输出只建立一个 DXGI 采集所有者。多个客户端可以同时观看同一屏幕，每个会话仍拥有独立编码器、码率、帧率、传输和输入权限；关闭一个客户端只移除其订阅，最后一个订阅退出后才释放采集源。不同显示器各自拥有采集所有者。

Wayland 门户仍按系统授权会话生命周期处理；本轮没有把同一门户授权跨客户端共享。混合 HDR/SDR 客户端加入已有物理源时沿用该源已经打开的采集模式，不为后加入会话重新 duplication 同一输出。
