# Eclipse v0.24.10-rc4

## 虚拟显示器

- 串流中可以保存被控端虚拟显示器的分辨率、刷新率和 HDR 设置。Windows 改变源画面尺寸时，支持模式续接的客户端会在原会话中重新准备该屏。
- 默认控制授权包含虚拟显示器管理，可以用串流窗口的加号创建虚拟屏。已细分的设备授权仍按各自开关执行。
- Windows 的「服务管理 → 虚拟显示器 → 驱动与诊断」新增「清理并重装驱动」。在主机空闲时移除当前 Eclipse 配置的自建屏及其保存的设置，再重新安装签名驱动。重装会换用干净的驱动配置，第三方驱动正在使用时会停止并说明原因。
- 认证后的 Windows 无头主机可以用已安装的签名驱动临时创建一块显示器。最后一路使用它的串流结束后回收。

## 串流与连接

- 串流菜单里的「退出当前串流后锁屏」可调整本次主动退出时的行为，初值沿用主机策略。主机会等最后一个会话结束后再锁屏。请同时更新控制端及被控端。
- TURN 服务器连接可以按自动、强制直连和强制中转三种方式启动。命令行能测试 UDP NAT 行为，串流诊断能显示实际选中的路径。
- HUD 的 BW 显示当前显示器视频码率。服务管理显示本机后台与当前程序的提交版本差异。
