# v0.20.10

本版固定已交付的插件界面恢复与模块管理改进，同时统一程序文件名并精简 Windows 分发体积。

## 插件界面与模块

- 恢复原设备页、图标、预览、远程协助及连接服务中的账号控件。顶部入口统一为“UU 兼容客户端”，位于应用设置左侧。
- 插件总开关默认关闭。手动启用后，兼容客户端与账号连接服务默认开启，实验性兼容服务器默认关闭，三者可分别选择并持久保存。
- 兼容服务器的控制、声音和剪贴板权限在服务管理直接显示。独立服务器使用共用传输，但不连带发布已关闭的原生入口。
- 官方中转默认关闭，允许后在 P2P 不可用时使用官方 TURN/UDP。远程协助页只保留官方设备 ID 与验证码流程。
- HUD 默认显示采集曲线；图例开关仅影响显示，统计持续记录。

## 分发与更新

- 主程序为 `eclipse.exe`，命令行为 `eclipse-cli.exe`；安装器与后台服务兼容旧版本的程序名称和安装记录。
- Windows 分发副本精简符号，构建目录保留排障符号。完整包包含运行所需的共享 SDK 与动态库。
- [UU 插件](https://github.com/TheRainstorm/uu-client-plugins/releases/tag/v0.20.10)继续独立分发，必须与本版主程序匹配。请完整更新主程序及 SDK，再安装对应插件，并退出旧主页和串流窗口后重新打开。
- 后台服务使用独立受保护目录与配置，更新后需显式导入匹配插件；不会静默复制账号或重启正在使用的共享。

## 验证与边界

发布前的功能版本通过核心 366 项、GUI 182 项和插件 122 项回归。实际 Windows DLL 的八种模块组合、页面绘制、禁用后拒绝新请求、错误配置恢复和 120 帧合成音视频检查通过。

真实官方手机客户端互通仍待验收。高帧率时的光标跟随与呈现节拍正在继续 profiling；Est.Total 是阶段估算，视频端到端不包含完整输入响应。Windows 主机偶发 DXGI 重连失败仍在排查。
