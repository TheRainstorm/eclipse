# v0.12.0：统一设备授权、多入口共享与账号设备管理

本版本冻结设备工作区重构前的功能，作为后续客户端／服务端设置分离的回退基线。

- 原生设备支持 IP 直连、UU 账号寻址和自建连接服务；多地址设备记录共用原生公钥授权，首次使用八位短码配对。最多四个观看会话，键鼠与手柄由持有控制权的会话操作。
- 原生主机增加 Windows / Linux Intel 硬件编码后端，支持 H.264、HEVC、AV1 的协商路径及 CBR / VBR；实际格式以运行时硬件能力为准。Linux UU 兼容串流可优先选择 HEVC。
- 增加 Wayland 门户共享、原生切屏、主机编码与输入确认时序、可关闭的局域网发现，以及手柄和陀螺仪传输与虚拟设备后端。
- 扫码登录和共享本机共用名称，默认使用电脑名；允许更新 UU 名称，查看本账号的设备并确认解绑，保留原生身份与授权。官方客户端与本客户端使用独立注册资料，同名不会在本客户端中自动合并身份。
- 改善全屏悬浮菜单、配对与离线错误提示；Windows 安装支持同卷归档、失败回滚与正确解析相对路径，分发包包含标准 Intel VPL 调度器。

## 已知限制

- Intel VPL HEVC CBR 在部分已测环境动态降码率时返回 `MFX_ERR_INCOMPATIBLE_VIDEO_PARAM`，尚未修复；不能把初始化成功等同于整场串流可用。VBR 的已测路径通过，实际结果仍依赖显卡与驱动。
- Linux 的 VPL 编码除调度器外还需要适配 GPU 的运行时；安装包不包含显卡驱动。部分硬编路径仍含 CPU 转换或上传，不承诺全程零拷贝或所有 GPU 的 4K60 性能。
- 真实 Wayland 桌面授权、实体手柄与驱动、不同 NAT 环境、UU 云并发、认证后的设备改名／解绑及官方客户端共存仍有实机验证缺口。自动化状态与生成媒体测试不替代这些验收。
- 原生显示参数上限和格式切换能力以现有协议实现为准；本版本尚未完成后续的客户端多配置、最后画面预览或新设置布局。
