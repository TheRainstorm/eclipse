# Eclipse v0.24.7

本版修复 Windows 控制端使用老板键隐藏并恢复串流窗口后，鼠标可操作、键盘却无响应的问题。

## 键盘恢复

恢复窗口时，界面可能还保留热键的 Ctrl/Alt 状态。此前原生输入已消费对应按下和抬起，界面回退又根据旧快照补发按下，使远端误以为修饰键一直按住。切到其它本机窗口会释放全部按键，所以 Alt+Tab 曾能暂时恢复；点击串流内部无法触发这个释放。

现在原生窗口或系统捕获有效时，修饰键统一由原生路径处理，界面不再根据聚合快照重复注入。普通界面输入继续同步自己的修饰键。该规则同时覆盖窗口和全屏模式，不依赖某个老板键组合。

新增隔离回归并纳入 CI，验证旧 Ctrl/Alt 快照、原生捕获与界面回退之间的归属，以及失焦、只读和本地菜单输入门禁。

- 校验和：`SHA256SUMS`

这项键盘修复位于控制端，请更新发起串流的电脑，退出旧串流窗口和托盘后重新打开。使用对应版本、平台和 SDK 的插件。

本版包含 [0.24.6](v0.24.6.md) 的锁屏策略、持久虚拟屏、后台更新及壁纸改进。Windows 被控端使用这些新功能时，也需更新实际后台服务。回归和编译检查通过，真实桌面使用体验仍需按自己的操作场景验证。
