# v0.15.0：嵌套快捷键、流式设置与自动编码顺序

- Ctrl+Alt+F12 可切换 Ctrl+Alt 客户端命令的归属：关闭时由本机处理，开启后除 F12 外发送到远端，适合 Eclipse / 远程桌面内外嵌套。状态随客户端配置保存，串流设置和串流菜单均可查看。
- 修正系统捕获活动时 Win 组合键的所有权，避免 Win+V 同时触发远端剪贴板和本机开始菜单；Win+Shift+方向键等组合同样整条归属远端或本机。
- 串流菜单保留显示器、画质和声音等快捷入口，画质菜单增加自动 / H.264 / HEVC / AV1 编码切换；UU 兼容模式提供 H.264 / 优先 HEVC。
- 原“软件设置”改为“串流设置”。原生设备串流可把当前设置保存到设备当前命名配置；普通“保存并应用”仍只影响当前窗口，断开后重新加载 profile。
- 串流菜单移除“关于软件”；版本、构建和许可仍在应用设置的“关于”页查看。
- 设备根页顶部设备、设置和停止服务图标改为白色，运行服务使用更明亮的绿色。
- 自动编码协商按 AV1 > HEVC > H.264，服务器默认编码优先于客户端明确选择，客户端选择作为回退。

## 升级说明与边界

- 本版沿用 v0.14 的四主页、服务管理、设备工作区、AV1 与 Windows H.264 MFT VBR；升级保留账号、设备配置和原生授权。
- Windows 桌面上的 Win+V、双层客户端 F12 透传仍应实机验证；状态回归不能替代真实桌面交互验收。
- Windows H.264 VBR 由 Media Foundation 执行；HEVC / AV1 和 Linux VBR 仍需要目标 GPU 的 Intel VPL 运行时。
- 原生目前最高 4K60；自动编码顺序只决定尝试顺序，最终格式仍取决于主机允许、驱动和客户端解码能力。
