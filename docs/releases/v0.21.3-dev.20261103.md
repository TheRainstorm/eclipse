# Eclipse 0.21.3-dev.20261103

本开发版改进串流窗口、虚拟显示器操作和垂直同步时的输入调度。正式发布前仍需实机验收，不覆盖既有稳定标签。

- 悬停主页或串流窗口顶部的软件图标，可查看二进制实际版本、精确 Git tag 及完整 commit。没有精确 tag 时不借用旧版标签；相邻安装清单仅用于交叉核对。
- Windows 浮动窗口启用系统阴影、圆角及随焦点变化的边框，主窗口补充细轮廓。最大化和全屏保留完整矩形；系统不支持的外观按平台能力降级。
- 同一设备的新建虚拟显示器归入原设备组，各显示连接、控制器及虚拟屏租约独立。双屏另开窗口时保留原连接与另一屏，支持合并回工作区。
- 软件设置可保存命名的虚拟显示器创建规格，配置分辨率、刷新率和HDR。左键“+”使用默认规格，右键选择；修改只用于之后的新建屏幕。
- Windows 应用显示器位置或主屏调整导致 DXGI 失效时，暂停采集和输入，重新找到同一个输出后恢复原连接。此恢复要求像素宽高、旋转和HDR模式不变；改变模式仍需另行协商。
- Windows 原生视频呈现改为先检查交换链就绪状态，队列繁忙时让界面线程继续处理输入，再重试最新画面；保留垂直同步和现有画质。不把失败提交记为已显示，也不为历史画面新增排队。

## 更新与验证

使用完整开发包更新，完全退出旧主页和串流窗口再重新打开。被控端的位置恢复需要对应后台代码，请在服务空闲时单独更新后台。现有配置与配对保留，插件须与包内SDK匹配。

Linux 核心413项、界面252项测试通过，分别有1项、4项原有忽略测试未执行；Windows目标编译、非阻塞呈现6项定向测试、DXGI观测9项定向测试通过。生成双流与自有窗口测试用于验证生命周期，不代表实际显示器已经验收。

真实DWM外观、Windows真实布局调整与双物理屏，以及垂直同步鼠标手感和拍照帧延迟仍待实机确认；当前没有足够证据承诺物理延迟已减少若干帧。
