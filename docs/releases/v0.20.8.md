# v0.20.8

本版改进 HUD、串流诊断和软件设置，并统一默认客户端快捷键。

## HUD 与串流诊断

- HUD 只保留精简模式；“更多 → 启用 HUD”直接切换显示，菜单提示使用当前实际快捷键。
- 支持在串流设置中调整 HUD 垂直位置和主栏、诊断背景不透明度，范围为 0–1；旧配置自动补默认值。
- BW 显示本机链路吞吐，与 RTT、Loss 组成蓝色网络行；编、解、渲染和排队在诊断中分别列出。
- Est.Total 显示最近三秒完整阶段分量和采样的均值 ± 标准差，并增加“估计”虚线。标准差表示估计值波动，与端到端区间误差分别解释，不替代同帧端到端观测。
- 顶部 3/10/60 min 同时控制诊断统计和图表范围；保留有界六十分钟历史，长窗保留尖峰、误差极值和缺口。
- 诊断左右内容比例为 6:4，图例标签单行、无边框并增加文字内边距；修复悬停移出闪现，固定面板失焦后保持显示并释放文字选择的键盘占用。

## 设置与快捷键

- 应用设置拆分为常规、外观、快捷键、设备发现和关于。分类切换保留草稿，恢复默认只作用于当前分类。
- 设备列表背景右键支持刷新壁纸。
- 所有默认客户端快捷键增加 Shift，统一为 Ctrl+Alt+Shift，保留原按键及用户自定义组合和禁用状态。详见[快捷键说明](../keyboard-shortcuts.md)。

## 更新与边界

使用完整安装包更新，并退出旧主页和所有串流窗口再打开新版。本版界面更新不要求重启远端主机。阶段估计不包含全部采集前等待、呈现和物理响应，不能用它与 E2E 的差值推算精确等待；本机接口吞吐可能包含其它应用的流量。统计口径见[HUD 说明](../hud.md)。

Windows 主机偶发的 DXGI 断链后重连失败仍未解决；UU 插件管理与官方中转属于后续版本内容，本版未加入。
