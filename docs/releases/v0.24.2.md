# Eclipse v0.24.2

本版本增加按私人设备组隔离的自建连接服务，完善服务器与设备管理、连接状态、主机提醒和程序更新。正式发布提供 Windows、Linux 主程序完整包，以及独立 Linux 连接服务包和校验和。

## 自建连接服务与公网串流

- 两台电脑使用同一设备组的接入码即可加入，码内包含 WSS 地址、组凭据和必要证书，无需重复填写内部设备编号。
- 在线目录支持双方发起连接；媒体优先直连，无法直连时可使用服务器签发的短期 TURN/UDP 凭据中转，设备配对与桌面权限仍独立校验。
- 不同用户分别建立私人设备组，目录和会话按组隔离；没有默认公共组或通用接入码。服务器提供本机建组、列组和导出接入码命令。
- WSS 支持自定义端口；部署、端口转发和 ICE/STUN/TURN 的作用见[连接服务指南](../connection-service.md)。当前中转仅支持 TURN/UDP。

## 服务器、设备和连接入口

- 连接页按 IP 直连、自建服务器及已启用插件组织。服务器同行编辑别名、保存、删除和启用；详情默认折叠，可查看和复制 WSS 地址与 Group ID。
- 每台服务器列出自己的在线设备，刷新与连接按钮分别对齐；刷新保留别名草稿和原列表，不影响其它服务器的查询。
- 添加设备使用服务器和在线设备下拉框，可快捷跳转添加服务器并返回原草稿。未启用插件从可选连接方式中隐藏，保存的配置继续保留。
- 新连接复用相同路线、已知身份或唯一同名的现有卡片，保留顺序、画面、配置和配对。可确认同一身份的重复卡片会合并；名称匹配不代替公钥校验。
- 自建路线统一显示服务器别名、WSS 域名及设备组；IP 路线保留地址和端口。入口按实际运行状态显示绿色可连接、等待、失败或停止，错误详情可悬停查看。

## 主机提醒、默认设置与更新

- 被控端在授权串流建立后显示三秒连接提醒，并保留最近200次连接历史。同一设备多屏连接避免重复提醒，历史仍按每次会话记录。
- 新配置默认关闭软件开机自启，开启自动启动服务和 HUD；已保存的设置保持原值。Linux 主机共享随应用运行，Windows 使用后台服务。
- 虚拟显示器驱动检测给出明确结果；缺少驱动时提示安装，在首次创建并启用虚拟屏时确认后衔接安装和启用。
- 修复老板键恢复时 Eclipse 未能回到前台的问题，恢复目标明确，其它窗口保留原显隐、最小化和几何状态。
- 服务更新只显示一个当前阶段进度。跨窗口和进程等待已有更新并复查结果，避免重复部署；自动路径只用顺序明确的较新完整包替换，手动仍可明确部署旧版本。

## 更新与验证范围

先退出旧窗口和托盘，再用对应平台完整包更新并保留配置与配对。Windows 还需完成主机服务更新，才能使用新的入口状态快照和主机功能。已运行的旧进程需要重开，才会获得新的更新协调规则。

主程序正式包不包含具体连接插件；需要插件时，请使用与本版 SDK 精确匹配的独立构建。连接服务部署需另行准备 TLS 证书、私人组和 coturn，安装包不包含服务器私有配置。

发布前功能回归已完成1222项测试，双平台全目标编译、生成界面预览、完整包来源与 SDK 校验，以及生成音视频和真实 TURN 中转探针均已通过。生成测试、同机公网探针及编译不能代替所有实体桌面、跨 NAT 拓扑和长期稳定性的实机验收；连接详情显示本次实际选中的媒体路径。
