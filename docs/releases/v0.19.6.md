# v0.19.6

Windows 原生串流使用 D3D11 直接合成 GPU 视频，减少 WGL 视频纹理的同步等待；菜单和 HUD 未变化时复用 GPU UI 图层。

- 视频通过共享 NT 图片和 GPU fence 交接，不在每帧经过 CPU 像素回读。现有解码器、远端光标、预览截图和不支持设备上的 WGL 回退继续使用。
- UI 图层依据几何、纹理、尺寸与 DPI 更新；视频与光标仍逐帧更新。隐藏帧不会等待尚未提交的消费序号，显示恢复和调整窗口尺寸会重新检查图层。
- HDR 依实际显示输出协商，保留 SDR 回退；scRGB 合成保持原有色彩转换和 egui 透明叠加语义。
- 一组 Windows 4K165 AV1 SDR 实流对照中，CPU 绘制均值约从 4.77ms 降至 0.34ms，Present 约为 0.28ms，邮箱等待中位数约从 5.14ms 降至 0.47ms，新画面约 162FPS，解码错误为 0。结果随设备和负载变化；这些是 CPU/API 阶段数据，不是实测输入到显示延迟。
- 生成 HDR/SDR 像素回归覆盖光标、半透明叠加、图层复用、尺寸切换、隐藏恢复和预览读取。测试显示器的系统 HDR 关闭，因此不能代替物理 HDR 输出验收。

高码率 PyroWave 的发送背压和吞吐限制仍在单独排查，当前版本不宣称已解决。控制通道 RTT 包含传输、队列和两端处理，与 ICMP ping 口径不同。

完整退出旧主页和串流窗口后重开。需要排查驱动兼容性时，可临时设置 `UU_D3D11_NATIVE_VIDEO=0` 使用原有 WGL 视频路径；该开关只用于诊断。
