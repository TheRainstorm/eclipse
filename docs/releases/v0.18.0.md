# v0.18.0：低延迟管线、连接恢复与图文剪贴板

本版包含 v0.15.1–v0.17.0 的功能及账号设备选择、登录状态与登出修复。原生主机与客户端建议一起升级；官方 UU 兼容模式保留自己的协议边界。

- 串流菜单拆分为“画面”和“编码”，提供常见/其它/自定义帧率，编码状态放入编码菜单；音量可直接输入，手柄归入输入。全屏悬浮入口默认开启。
- 修复 Wayland 多设备工作区的隐藏协调窗口仍呈现缓冲、产生空窗口并抢焦点的问题；全屏与跨屏检查固定操作可见串流窗口，普通主页保留正常显示。跨 DPI 后的尺寸调整持续到实际窗口大小稳定，处理迟到配置恢复较大或较小旧尺寸的问题；用户主动调整可接管。
- 服务管理增加“配对设置”，集中设备名、公钥、密码与授权；粘贴有效公钥时可从备注填写名称。启动服务即接收新设备申请，每次仍需批准。串流中可保存服务设置供下次启动使用，也可保存后重启。
- 修复 UU 迟到释放信令误关配对通道，以及准备失败、切换不支持格式后的会话清理；增加房间凭据续约和心跳超时重连。初连诊断分别记录采集、编码器与 ICE 准备；HEVC/AV1 解码探测并行，避免重复探测失败的编码器。
- Sway 等 wlroots 桌面在 ScreenCast 授权后可使用同合成器的虚拟键鼠，绑定所选输出并处理缩放。明确拒绝 RemoteDesktop 输入授权时保持只观看，不绕过系统授权。一次授权内保持捕获源格式稳定；源被移除时结束会话，停止重复发送缓存画面。
- 原生剪贴板支持双方许可的文字与 PNG 图片，修复客户端原生许可保存、失焦后恢复同步和未改变旧内容覆盖的问题。图片最多8MiB并限制像素和尺寸；大图分片有界，失焦、撤销与重连会取消旧待发内容。
- 原生两端协商有预算上限的 XOR 视频 FEC，每组最多8个数据包，可恢复1个缺失；原始视频立即发送，保留 NACK/RTX 和关键帧恢复。它不等同于 Sunshine RS 或官方 UU FEC。
- Windows 可选后台服务使用受保护安装和配置，在所属控制台用户登录后共享，Win+L 后保持媒体进程；支持管理员管理、远程配置、更新失败回滚和异常恢复。普通窗口共享仍受桌面权限限制。
- AMD 原生 AMF 三格式采用按需关键帧，在线码率调整保留参考链；其它后端保留各自重建规则。继续使用同设备 D3D11 纹理输入，并提前绑定采集设备，避免首帧再次初始化编码器；生成4K对照中，准备与首帧合计由约102–112ms降至38–45ms。
- DXGI 采集使用两个有界 GPU 快照槽，按帧租约安全复用；在4K生成源对照中，采集复制加编码中位耗时由约8.8–9.9ms降至7.3–8.3ms，同格式输出码流逐字节一致。修复解码器偶尔暂不出图、随后一次返回多图时旧帧永久积压的问题；每次输入收尽已解码输出，只交付最新图片显示。
- 修复 AMD AV1 在1080p、640×360等非默认对齐尺寸下的初始化与补边显示。按协商的可见尺寸裁剪，并在解码器恢复后保留显示范围；GPU 裁剪保留原 sample / 纹理租约，不增加CPU像素读回。
- Linux 与 Windows 打包入口先核验并复用同提交完整安装包，命中时不调用 Cargo；需要时用 `--rebuild` 强制构建。测试/check 与完整安装包分别记录，避免把检查完成当成可安装产物。
- 完成 v0.19 待办中的[官方手机客户端兼容可行性分析](../official-mobile-client-feasibility.md)：当前原生 server 尚不能供官方手机直接连接，后续需要独立的官方协议与准入适配。

## 验证与限制

验证包括 Linux 工作区的库、二进制及集成回归，原生 Windows 媒体、核心、剪贴板、GUI回归，以及独立窗口站图文剪贴板和临时 System/SCM 服务的安装、权限、更新回滚、配置重启、崩溃恢复与退出清理。真实 wlroots 门户在独立双屏合成器中完成两轮共36,000帧、运行中帧率调整和缩放键鼠检查，零解码错误；移除捕获源后133ms终止旧会话。完整 Wayland GUI另完成30分钟持续串流，94,863帧解码、零解码错误和输入/队列丢弃，检查隐藏协调窗口不映射、普通主页正常显示和退出；独立合成器使用软件渲染，该数字不代表真实 GPU 吞吐。

AMD 生成4K源的 H.264 / HEVC 各36,000帧 GPU 解码长测通过；AV1 在批量输出修正后完成36,000帧，5次暂未输出均在后续调用收回全部图片，最大滞后一帧，并以60次像素抽查验证。纹理池与非对齐尺寸另完成20组原生测试、690帧GPU硬解和69次像素抽查；其中12组4K对照验证复用前后码流相同。采集设备预绑定的准备加首帧改善来自另12组原生对照。加密视频 FEC 丢包恢复、双端图文剪贴板，以及本地假信令服务35分钟凭据续约也通过了专项检查。生成媒体、隔离窗口站、临时服务及独立合成器的测试，不代表工作电脑锁屏画面、物理显示端到端延迟或所有驱动已经验收。

Windows 后台服务需要管理员安装、所属用户已登录和有效显示输出；不自动解锁，不接管任意 RDP 会话，不能通过 SendInput 产生 Ctrl+Alt+Delete。主机应在[后台管理窗口](../windows-background-service.md)维护保护配置，更新普通程序后还需更新后台程序。

HDR、原生 NVENC、发送端包节奏、官方手机兼容入口、文件传输、终端和端口映射尚未实现。原始10–20秒初连尚未完整复现，官方 UU 长期在线仍需实际服务验证。高帧率和4K选项不保证所有硬件达到目标吞吐。

正式发布附 Linux x86_64 tar.gz、Windows x64 ZIP 与 `SHA256SUMS`。安装升级保留账号、设置与授权；现有主页和串流需关闭重开才使用新版。
