# Eclipse v0.21.1

本版更新串流诊断和输入时间线，改进 Windows 视频交付与原生呈现，并恢复远端显示器选择的记忆。

- HUD 按采集/编码、解码/呈现分组，显示实际输入送达、注入、源等待及输入至后继画面的时间区间。图表悬停补齐 Input→Frame；Clear 清除当前串流历史和统计基线，保留连接及实时测量。
- 已解码的 GPU 和平面画面及时交付，不再等待后续压缩队列排空；保留参考帧解码和批内最新图像策略。
- 原生合成复用未变化的场景，减少重复 Present；关闭垂直同步时调整翻转表面和设备队列额度，缓解 DWM 等待。去掉合成中相互抵消的颜色转换，保留最终 scRGB 输出。
- 按设备保存最后成功切换的远端显示器，重连后恢复。屏幕重新编号时按源名称匹配；暂时缺失或切屏失败时保留原选择。

## 升级

请更新完整安装包并退出旧主页、串流窗口后重开。**Windows 后台程序位于单独的受保护目录；更新普通程序目录后，还需在服务管理中更新后台程序并重新连接。** 仅升级客户端无法启用旧后台缺少的远端光标或主机计时功能。

主程序继续独立分发，UU 插件在[独立仓库](https://github.com/TheRainstorm/uu-client-plugins/releases/tag/v0.21.1)下载、手动启用；需要插件时请同时更新与本版 SDK 匹配的完整插件包。现有配置和配对记录保留。

## 测量与限制

输入至后继画面的统计不等于任意游戏的因果响应或物理输入到光子的延迟；区间误差与统计波动分别显示。高码率动态画面的呈现仍可能达不到目标帧率，本版未修改默认画质来换取统计帧率。DXGI 断链后的部分重连故障仍在排查。

计量口径及实测范围见 [HUD](../hud.md)、[输入时间线与呈现对照](../performance/input-timeline-and-native-presents.md)和 [Windows 延迟分析](../windows-latency.md)。
