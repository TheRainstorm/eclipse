# v0.20.7

本版汇总 v0.20.5 之后的原生呈现修复、UI 缓存改进及视频端到端观测。Windows 主机断链后偶发的 DXGI 重连失败仍未解决，限制见下文。

## Windows 呈现与性能

- 修复部分客户端进入全屏后整窗变黑、菜单和 HUD 一同不可见的问题。原生 D3D 呈现使用独立子窗口，与 WGL 窗口职责分开，并采用子窗口翻转交换链；不增加逐帧 `glFinish`、视频复制或 GPU 读回。全屏黑屏修复已完成真实 H.264、AV1 串流对照并获得用户确认。
- 按实际字库内容判断 UI 图层是否变化，避免重复的相同字体更新使原生 UI 缓存失效。
- 编码前 SDR 颜色转换使用显式分支跳过不需要的色调映射计算，保留原有滤波、颜色矩阵及同步规则。组件测量结果不能直接当作整条串流的延迟降幅。

## 视频端到端估测与诊断

- HUD 主项改为同一源画面从主机源呈现到客户端系统显示的估测，显示均值、误差范围和显示方法；原来的阶段均值小计保留在详情。
- 两端协商扩展后，使用源帧身份、四时间戳校时及 Windows 原生路径的 DXGI 回执关联。缺少身份、有效校时或显示证据时保持未知，重复画面和旧缓存重绘不会被当作新的首显样本。
- 区分真实观测丢弃与有界历史容量淘汰，分离解码帧身份关联和遥测聚合，减少测量处理对媒体路径的争用。
- 增加默认关闭的源帧、Present、采集原因和接收管线终止诊断，保留帧身份、事件完整性与失败边界，供离线分析。详见 [HUD](../hud.md)、[延迟统计](../native-latency.md)及 [Present 诊断](../present-observation-profiling.md)。

DXGI 回执提供依赖平台统计可信假设的经验区间，多显示器或其它全屏应用可能使统计不可靠；中点不是精确显示时间。视频端到端估测不包含面板像素响应，也不等同于鼠标到屏幕响应。当前仍有未定位的突发卡顿，不能声称已经消除。

## 已知问题与更新

Windows 主机曾出现正常串流突然断开、重新连接时 `DXGI: DuplicateOutput SDR` 返回参数错误 `0x80070057`。原因尚未确认，本版未修复该故障；后续重新连接成功也未证明能在同一个主机进程内自行恢复。

使用完整安装包更新。客户端更新后，退出旧主页和串流窗口再打开新版；要使用新的两端观测能力，共享端也需更新并重启对应共享进程。安装保留登录状态与设置，不会自动结束旧进程。旧主机或暂不支持回执的呈现路径仍可串流，端到端主值按实际能力显示未知或不支持。
