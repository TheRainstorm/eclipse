# v0.19.7

应用设置增加简体中文 / English 选择。保存后更新当前界面和已打开的新版串流窗口，重启后保留。

- 主页、设备、连接服务、共享管理、悬浮菜单、设置和 HUD 详情使用统一语言目录。仅翻译静态界面模板，设备名称、用户内容及远端返回的原始信息保持原样。
- 精简 HUD 沿用英文缩写；详情、悬停说明和三分钟曲线随应用语言切换。英文详情根据标题长度调整布局，窄窗保持边界限制并可滚动。
- 语言属于应用全局设置，独立设备画质配置和旧串流保存不会覆盖它。未设置语言的旧配置默认使用简体中文。
- 打开应用设置不会仅因快捷键迁移而显示未保存修改。
- Windows SDR 原生合成依据实际 GPU 图像启用；软件解码和不支持共享的图像使用原 GL 呈现，避免多余同步。HDR 仍使用实际协商的呈现能力。

完整退出旧版本的主页及串流窗口后重开，以免旧窗口保存不认识的新设置。软件自身界面语言可以切换；操作系统界面和远端软件不由此设置改变。部分间接显示器无法建立原生 D3D 输出时保留 WGL 回退。
