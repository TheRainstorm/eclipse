# v0.18.8 测试版：媒体重构首批测量

- 为原生主机加入有界逐帧轨迹，关联采集、同步编码调用、实际返回的编码输出、发送队列与首尾 RTP 写入 API 返回。编码输出按 PTS 匹配输入；报告分位数、样本窗口、溢出及无法匹配的观察。
- Windows 采集区分源帧 ID 与输出 PTS，保留源 QPC 时间和积累帧数，重复图像不再被当作新源图像；缩放保留这些元数据。
- 新遥测独立协商，并通过无序、短寿命、有界数据通道发送。旧控制统计和 UU 官方兼容链路保持原行为。提供本地报告工具和不接触桌面的生成源自环 probe。

这是[媒体重构方案](../streaming-latency-and-stability-plan.md) R0 的主机测量部分，详见[逐帧测量说明](../frame-tracing.md)。尚未完成客户端解码/呈现追踪、GPU 完成查询、AMF 转换池、异步流水线和其余阶段，**本版不能作为延迟优化已达标的交付**。后续按同条件基线选择并验证优化。

两端使用新版才能在客户端诊断中收到主机新报告；旧端仍可串流。此版先提供独立测试产物，不覆盖正在测试的 0.18.7，不创建正式 Release。
