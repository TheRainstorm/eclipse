# uu-client 0.5.0 · 原生剪贴板与首次使用完善

原生局域网共享补齐双方许可的文本剪贴板；UU 兼容模式恢复默认 PC 请求签名配置，避免正常升级后设备列表无法加载。改进设备首页加载、错误反馈与软件编码源尺寸提示。

## 原生文本剪贴板

- 主机共享时明确允许，控制端在当前串流菜单再次开启；两端默认关闭，重新连接需重新授权。
- 支持最多30 KiB UTF-8文本，不传输图片、文件或富文本。首次同步以控制端为来源，主机已有内容保留为基线，不主动广播。
- 独立加密可靠通道，限制积压；失焦、停用、撤销许可或断线时暂停，拒绝上一激活代次的迟到消息。仅观看模式可接收已许可的文本，不发送本地文本。
- Windows 共享端可以在后台执行已授权的同步，控制端保留前台限制；Linux 使用桌面允许的剪贴板后端。失败不停止视频、声音或键鼠。
- 旧版可以拒绝新增通道，已有音视频和键鼠继续。详见[文本剪贴板说明](https://github.com/TheRainstorm/uu-client/blob/master/docs/native-clipboard.md)。

## 设备首页与默认配置

- UU 兼容模式明确内置 PC 客户端共享的 HMAC 请求签名值，首次使用无需手工创建签名文件；账号仍需扫码登录，设备操作仍受账号与会话权限控制。
- 该共享值可从源码和程序读取，不属于个人账号令牌，也不代表官方接入授权。源码不做混淆，不把私有配置上传CI。可选本地文件优先；显式文件错误时清楚报错，不悄悄更换配置。旧0.1–0.4安装包仍要求本地文件。
- 首次设备加载失败时在中央显示原因与重试入口，区分加载中、真正空账号与失败；无效服务响应不再当作空列表。
- 设备列表先显示，预览异步加载。缩略图请求有超时、大小、解码和队列限制，慢图片不阻塞快图片；刷新与切换账号可取消旧图片任务。
- 不再把完整壁纸像素保存在设备对象中，减少主页重复复制和内存占用；刷新保留当前设备选择。

## 其它改进与验证

原生软件H.264编码提前校验显示源尺寸，支持偶数尺寸且最大3840×2160或2160×3840。超限显示清楚说明，不更改用户显示配置。

验证包括加密剪贴板许可/代次回归、Linux双独立Xvfb实际双向复制、Windows全新非交互窗口站内的真实剪贴板检查，以及真实本地HTTP预览、慢响应取消和资源上限。测试只使用生成文字/图片，避免读取工作桌面的真实剪贴板。

历史EXE触发的一条Atlassian告警已证实为Rust编译器COFF符号误报；按误报处理，仓库秘密扫描与推送保护保留。个人账号、二维码、邀请和本地覆盖文件仍禁止进入源码与安装包。

## 安装与限制

从本版本Release下载双平台包，校验 `SHA256SUMS` 后安装。Windows退出旧窗口，解压运行 `install.ps1`；Linux解压运行 `python3 install.py`。升级保留账号、软件偏好与本地覆盖文件。

原生模式仍为局域网、单控制端、单显示源的软件H.264串流（1–60 FPS），未实现硬件编码、H.265/AV1/HDR、运行中切屏/画质、Wayland portal采集或公网发现。Linux包需兼容Ubuntu 24.04的glibc与桌面运行库，Windows包未做Authenticode签名。完整方向见[产品远景](https://github.com/TheRainstorm/uu-client/blob/master/docs/vision.md)。
