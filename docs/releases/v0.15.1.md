# v0.15.1：输入、画质菜单与 AMD 原生 AMF 修复

这是 v0.15.0 的修复版，原 v0.15.0 标签和安装包保持不变。

- 修正原生键盘修饰键的按下 / 抬起生命周期，停止重复保活，并在主机忽略已按住修饰键的重复按下；用于处理 Win+V 松键后剪贴板消失和开始菜单误弹的问题。
- 修复原生画质快捷菜单，协商完成后可调整码率、帧率、分辨率和编码，并显示实际协商格式。UU 兼容串流的画质偏好可保存供下次连接使用。
- 服务器默认编码支持自动。服务器明确选择优先；服务器自动时采用客户端明确选择；双方自动按 AV1 → HEVC → H.264 尝试。明确选择不可用时报错，不再静默降为 H.264。旧配置中的显式 H.264 仍保留。
- 修复 Windows HEVC / AV1 编码器枚举、初始化和 AV1 时序字段解析，避免选中其它编码后仍只使用 H.264。
- Windows AMD 使用原生 AMF，在同一设备完成 DXGI 纹理缩放、颜色转换与编码，常规 GPU 输入不回读 CPU。另包含 AMF CPU 输入资源生命周期修复，使用框架分配的 NV12 平面承接上传。
- 画质菜单支持即时切换垂直同步，平台拒绝时显示实际状态。

## 验证与边界

- AMD 生成纹理 4K 编码调用约 8–10ms，对照原 MFT 路径约 43ms；这不是实际桌面采集或端到端延迟。三格式已有跨机硬件解码验证。
- Win+V 松开 Win、双层客户端快捷键透传仍待真实桌面验收，状态测试不能替代该结论。
- 本版保留 v0.15 的功能范围，尚不包含 v0.16 的多设备共享窗口、新配对及远程服务管理，也不包含 v0.17 的突发恢复与日志轮转。
- 视频 FEC、完整零拷贝、HDR 未实现。硬件可用格式与实际吞吐受显卡和驱动限制。

Windows ZIP / Linux tar.gz 均附版本与逐文件清单，压缩包校验和见 `SHA256SUMS`。升级保留本地设置和授权；关闭旧窗口后启动新版，运行中的进程不会自动升级。
