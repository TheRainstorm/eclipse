# v0.18.10：客户端码率模式、原生远端光标与 HUD

客户端“编码 → 码率模式”可选择跟随主机、CBR 或 VBR。主机提供默认值，客户端明确选择只影响自己的会话；新两端可在连接内切换，初始化失败保留原编码器并回报原因。VBR 峰值随客户端目标码率调整为两倍。旧主机和不支持的后端会明确提示，UU 官方兼容串流保持原行为。

Windows 原生主机新增 DXGI 独立光标采集和有界状态传输。客户端支持本地和远端、仅远端及隐藏，按源屏幕坐标合成颜色和 AND/XOR 光标，不新增整帧 GPU 读回或视频等待队列；RGBA 兼容路径只处理覆盖区域。支持该功能需要更新两端，旧主机的仅远端模式仍不可用；进入本地菜单会恢复本机指针。边界和延迟说明见[原生光标](../native-cursor.md)。

HUD 将 Capture、Encode、Decode 和 Render CPU 放在一起，网络、帧率、排队分别显示；移除主面板的粗略延迟合计和“输入到光子未测”。详细累计计数、输入确认及计时范围仍可悬停查看，不改变原有统计口径。

补充[优化适用范围](../performance/optimization-scope.md)：Intel 等硬件可使用适用的 GPU 路径和客户端优化，AMF 输入表面复用仅对 AMD 生效；独立采集等未晋级实验仍默认关闭。此前的主机局部收益不代表所有编码器或端到端延迟。

本版继承 [0.18.9 的混合 DPI 字库缓存、文字色彩和悬浮菜单修复](v0.18.9.md)。PixPin 首次截图的全屏窗口变化仍未解决；没有宣称所有硬件、桌面输入或长期稳定性均已验收。

验证入口包含真实加密光标通道、GPU/RGBA 光标像素、既有视频格式/色彩回归，以及只使用生成图案的原生硬件 CBR/VBR 切换探针。测试通过的范围以发布时实际验证记录为准，不将编译或生成图案检查当作用户桌面验收。

使用完整安装包升级并重开旧窗口。只更新客户端即可使用新 HUD；码率模式和 Windows 独立光标需同时更新主机。旧版本标签及完整包保持独立。
