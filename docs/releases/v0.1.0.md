# uu-client 0.1.0 · 跨平台基础串流

这是面向 Windows 与 Linux 的基础串流 demo 里程碑。

- 原生 H.264 串流，Windows D3D11VA / Linux VA-API 硬解与软件回退。
- Opus 音频、音量与静音，Ctrl+Alt+M 快捷切换。
- 键盘标点与组合键、鼠标中键、绝对 / 相对鼠标模式、本地 / 远端光标。
- 多显示器标签、切屏与排序，多设备独立窗口，设备主界面保持打开。
- 画质、码率、帧率设置，统计 HUD、可隐藏悬浮入口及全屏快捷键。
- 账号登录退出、双向文本剪贴板与本地偏好保存。

## 下载与安装

Windows x64 下载 ZIP，解压后运行 `install.ps1`；Linux x86_64 下载 tar.gz，解压后执行 `python3 install.py`。安装前退出旧窗口。安装器校验文件并保留本地登录态与设置。`SHA256SUMS` 用于核对下载完整性。

Linux 包在 Ubuntu 24.04 上构建，需要兼容的 glibc、VA-API、GBM、ALSA 和 OpenGL/EGL 运行库；Windows 包未做 Authenticode 签名。

## 使用前需要配置本地凭据

**源码和安装包均不包含第三方生产签名密钥。** 首次使用须按项目的[连接凭据说明](https://github.com/TheRainstorm/uu-client/blob/master/docs/connection-credentials.md)配置有权使用的本地凭据，否则不能登录或连接官方服务。构建和 CI 不需要该凭据。

为移除不应分发的凭据，早期 Git 历史已重写并移除含凭据的旧 EXE；持有旧克隆的开发者请重新克隆，避免合回旧历史。

## 当前限制

当前是兼容主控客户端；自有被控端与自主网络尚未交付。H.265 / AV1、HDR、视频 FEC、文件传输、终端和端口映射尚未实现。实际帧率、画质与恢复体验受被控端、GPU 和网络影响，仍需持续打磨。
