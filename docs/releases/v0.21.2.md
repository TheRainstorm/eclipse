# Eclipse v0.21.2

本版修复 Windows 后台升级后程序路径变化导致防火墙规则失配的问题，并把原生串流收敛到固定端口池。

- 启动共享时异步检查防火墙；缺少当前程序规则时，通过 Windows 管理员授权配置必要规则并提示结果。检查失败仍显示具体原因，不阻塞界面。
- 后台升级只迁移精确绑定旧程序路径的本机规则，保留启用状态、Allow/Block、网络类别、地址、协议和端口等原有条件。失败时只补偿仍与本次修改结果一致的规则，保留管理员并发修改。
- IP 控制入口 TCP 48998、局域网发现 UDP 48999；串流 TCP 握手及 UDP 媒体在 49000–49009 内按实际绑定分配。端口池耗尽明确报错，不回退随机监听端口。TCP 和 UDP 独立分配，端口总量不等于并发显示器数量；公网 NAT 映射仍可能改变外部端口。
- 包含此前的串流标签与独立窗口、虚拟显示器创建和回收、壁纸收藏及托盘改进。认证成功的连接不再占用临时握手许可；实际容量仍受端口、硬件及系统资源限制。

## 升级

使用完整包更新普通程序，退出旧主页和串流窗口后重开。Windows 后台位于单独受保护目录，需在服务管理中单独更新；更新后台会断开其当前串流，请在空闲时操作。现有配置和设备配对保留，插件须匹配当前完整包 SDK。

新建防火墙规则限定当前程序及必要端口，仅覆盖 Domain/Private；已有禁用、Block、受限规则或组织策略不会自动放宽。规则存在不等于远端一定可达，网络类别及上游网络仍需满足连接条件。

## 验证范围

防火墙精确范围保留、冲突检测及部分失败补偿已验证；Windows 生成图双流和断开清理已验证。真实桌面的 UAC 提示、后台更新及多显示器操作仍需用户验收；生成图与编译检查不能替代桌面验收。
