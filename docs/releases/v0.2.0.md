# uu-client 0.2.0 · 原生局域网观看

新增实验性的自有主机与图形观看通路：两端使用本项目，不需要 UU 账号、第三方服务签名密钥或互联网服务。现有兼容客户端继续保留。

- Windows DXGI / Linux X11 真实桌面采集，支持枚举与选择当前显示源；保持原有显示器布局。
- 软件 H.264 编码，默认60 FPS、8 Mbps，可在主机启动时指定1–60 FPS与码率。
- 每次主机会话生成短期私有邀请；固定证书 TLS1.3 认证后交换 WebRTC SDP，视频采用 DTLS-SRTP，支持 NACK 重传与关键帧恢复。
- 主页打开或拖入邀请，无需登录；独立观看窗口、HUD、全屏与退出快捷键，主页保持打开。
- 原生观看菜单按实际能力显示；兼容账号的登录或退出不会断开独立原生会话。
- Windows 在视频开始前准备解码组件，减少驱动冷启动造成的队列溢出；保留硬解失败后的软件回退。
- 修复 Wayland 不同 DPI 输出之间移动时的窗口尺寸；新增无头 Sway 全屏、系统快捷键与跨 DPI 往返 CI 检查。
- 登录状态改为私有临时文件原子替换，避免多窗口读取半写入数据；隐藏账号和二维码的调试凭据，发布守卫识别改名后的账号文件。

## 试用原生观看

解压安装包后，在终端启动不会读取真实桌面的合成画面主机：

```text
uu native-host --synthetic --invitation-file ./demo.eclipse-invite.json
```

打开 `uu-gui`，选择“使用原生邀请”，填写该邀请文件路径。Windows 命令行使用 `uu.exe`。默认只绑定本机回环；跨设备局域网连接、真实显示器采集和邀请保护见[原生串流说明](https://github.com/TheRainstorm/eclipse/blob/master/docs/native-streaming.md)。

## 安装与范围

Windows x64 下载 ZIP，解压运行 `install.ps1`；Linux x86_64 下载 tar.gz，解压执行 `python3 install.py`。安装前退出旧客户端；安装器校验文件并保留本地登录态与设置。下载后可使用 `SHA256SUMS` 校验完整性。

原生模式目前为**单控制端、单显示源、纯观看**。尚无原生音频、键鼠注入、剪贴板、运行中切屏/画质、Wayland portal 采集、跨公网连接或无人值守管理。兼容客户端已有的远控功能不代表原生主机也已支持。

UU 兼容模式仍须配置你有权使用的[本地连接凭据](https://github.com/TheRainstorm/eclipse/blob/master/docs/connection-credentials.md)，包内不含第三方生产密钥。Linux 包基于 Ubuntu 24.04 构建，依赖兼容的 glibc、图形与音频运行库；Windows 包未做 Authenticode 签名。
