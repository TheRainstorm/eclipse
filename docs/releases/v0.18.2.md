# v0.18.2：输入恢复、手柄与设备状态

- 键鼠注入暂时失败或队列满时，撤销旧控制权、清理本会话输入并恢复后端；等待新的控制请求，不回放旧输入。此前一次失败就可能让输入线程永久退出，而画面继续运行。新增服务端错误日志与客户端控制状态诊断，便于定位实际 Windows 桌面/API 错误。
- Xbox 类实体手柄模拟 Xbox 360，NS/PS 类模拟 DS4 并保留可用的陀螺仪与加速度数据。Windows 使用 ViGEmBus，Linux 分别使用 uinput/UHID；兼容旧端的 DS4 通道。ViGEm 设备枚举后短暂未就绪时有界重试，避免反复拔插。
- 修复 Windows 实体手柄只能读到扳机、按钮与摇杆始终为零的问题：采样线程持有并运行 SDL 的 Windows 消息泵，使 Raw Input 报告得到处理，不创建可见窗口或抢占焦点。
- 设备详情可固定当前截图；固定后不被后续串流截图覆盖，取消固定后恢复更新。
- 设备主页显示在线、离线或状态未知，IP、UU、自建入口任一在线即可。明确离线的卡片变暗，仍可连接、编辑和刷新；查询失败或缺少登录不误判离线。自建入口在线查询需同时升级连接服务，不支持的旧服务显示未知。
- Windows 后台管理直接使用当前 GUI，不依赖旁边的旧 CLI。安装、更新和账号同步预检完整安装包与文件哈希，混合版本显示具体文件；管理员操作与窗口启动失败会弹窗显示原因。

键鼠后端修复需升级被控端后重连。Xbox/DS4 类型协商需两端升级；只升级控制端时旧主机继续使用 DS4。后台服务还需在主窗口执行“更新后台程序”，仅更新普通程序不会替换已经运行的受保护服务。请完整解压 Windows 安装包，保留清单和运行库。

验证包含 Linux 工作区回归、Windows 原生 GUI 回归、SDL 虚拟热拔插、加密手柄通道授权，以及 Windows 自有 Xbox 虚拟设备的 XInput 实际状态读回。实体蓝牙手柄的 SDL 按钮和摇杆采样已通过修复前后对照；实际游戏内操作、工作电脑的真实锁屏及 UAC 桌面仍有实机验收边界。

使用说明见[手柄](../native-gamepad.md)、[后台服务](../windows-background-service.md)和[设备与设置](../client-and-server-settings.md)。正式发布附同提交 Linux、Windows 完整安装包及 `SHA256SUMS`。
