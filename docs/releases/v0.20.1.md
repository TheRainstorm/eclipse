# v0.20.1

HUD 详情移除「串流诊断」标题和「复制详情」按钮，保留拖选文字与 Ctrl+C。分类和数据首行采用相同的顶部对齐，窄窗口换行后仍对应各自分类；悬停说明和三分钟曲线保留。

悬浮菜单统一使用状态标签与开关。HDR 的当前状态放到同行，详细条件改为悬停说明；自动协商编码的右侧显示实际编码。声音使用独立播放开关、精简音量卡片和可拖动或直接编辑的百分比，静音保留原音量。输入、剪贴板及 HUD 的二态项使用相同开关样式，格式和画质等多选项保留明确选中标记。

验证包括 GUI 170 项回归，以及隔离 Xvfb 上生产 HUD 的宽窄窗口、分类基线和实际菜单渲染。键盘捕获与菜单焦点规则保持现有实现；真实桌面观感仍请安装后验收。

使用完整包更新，退出旧主页和串流窗口后重开。后台服务无需为界面变化重启。
