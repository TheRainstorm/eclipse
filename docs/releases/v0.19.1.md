# v0.19.1

新增 LAN Quality 推荐码率，并修复部分 Intel 显卡被误判为不支持 PyroWave 的问题。

- 新配置默认使用推荐码率。按实际输出分辨率、目标 FPS 和最终编码计算；悬浮菜单、设置页显示推荐值，保留固定档和自定义值。
- PyroWave 使用上游良好画质经验曲线，1080p60 约 170 Mbps、4K60 约 288 Mbps；替换最初按像素数线性放大的估算。帧率翻倍时目标码率约翻倍。
- H.264 / HEVC / AV1 使用分别计算的目标；自动编码回退时重新计算，在线调整 FPS 时同步更新。
- Windows PyroWave 能力探测验证实际使用的 NT 纹理、D3D fence 与 GPU 解码，不再要求未使用的旧式 KMT 共享句柄。

推荐值是良好画质的经验起点，不能保证所有内容的严格最低码率；原生主机需更新并重启共享后使用新规则。UU 兼容模式的自动画质仍由官方主机决定。具体参考表和边界见 [LAN Quality 推荐码率](../bitrate-recommendations.md)。

PyroWave 继续作为实验性 SDR / 8 bit / 4:2:0 / CBR 格式。低码率跨机 GPU 串流已通过短测，高码率组仍观察到大量丢包，尚未完成定位与稳定性验收；不应把生成图的 GPU 速度当作高码率网络或端到端性能已通过。[实现范围与测量口径](../pyrowave.md)。
