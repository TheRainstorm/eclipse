# v0.20.9

本版将 UU 功能改为独立下载的运行时插件。用户已确认插件启用、关闭正常；兼容页面的图标、原设备布局和远程协助入口布局仍待后续恢复，本版保留当前界面。

## 独立插件

- 主程序只提供原生串流、设备授权和通用插件能力，不再包含 UU 静态依赖或插件子模块。
- UU 插件在[独立仓库](https://github.com/TheRainstorm/uu-client-plugins/releases/tag/v0.20.9)分发。下载与本版匹配的 ZIP，解压到软件目录，在“应用设置 → 插件管理”扫描并手动启用。
- 所有安装默认关闭插件；安装或发现清单不会运行插件代码。停用后不再接受新连接，已有串流保持存活。旧账号和路由仅在手动启用后由插件迁移，并保留原件。
- 共享 SDK 按源码、编译器、平台与编译选项精确匹配；主程序升级时需更新相应插件。插件和主程序具有相同的进程权限。

## 连接与更新

- 官方中转默认关闭，可在插件设置中显式允许 TURN/UDP。修复 TURN 密码凭据类型声明；暂不支持 TURN/TCP 或 TURN/TLS。
- 插件声明帧率、编码与自动码率策略，主程序按能力显示选项。输入、显示目录和媒体生命周期共用引擎契约。
- Windows 完整包包含共享 SDK 和 Rust 运行库，必须完整更新，退出旧主页及串流窗口后再启动。后台服务使用独立受保护配置，安装新版后需显式导入匹配插件；不会静默复制用户账号。

## 验证与边界

核心 365 项、GUI 181 项、插件 107 项回归通过；独立插件实际加载与启停、强制 TURN 生成媒体及 Windows SDK 导入符号核验通过。用户确认插件开关正常。协议和生成媒体检查不替代真实官方手机客户端互通验收。

Windows 主机偶发的 DXGI 断链后重连失败仍在排查。精简 HUD、分钟图表、分类设置与默认快捷键沿用 v0.20.8。
