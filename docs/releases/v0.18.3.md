# v0.18.3：Windows 安全桌面输入热修复

- 修复管理员确认（UAC）或锁屏触发桌面切换后，画面仍在而键鼠无法操作的问题。输入线程原先打开的桌面句柄缺少 `SendInput` 所需的 `DESKTOP_JOURNALPLAYBACK` 权限，Windows 因而拒绝输入并返回错误 5。
- 输入线程取得包含该权限的桌面句柄；采集线程保持原有访问权限。同名桌面也会检查本线程拥有的句柄权限，必要时重新绑定，避免只比较桌面名称而跳过修复。重复同步保持句柄及按键生命周期，返回普通桌面仍按既有规则释放本会话持有的输入。

被控 Windows 端需完整更新程序，并在主窗口执行“更新后台程序”，然后重连。只更新 GUI 或重启旧后台服务不会应用修复。后台服务须已安装并运行，控制台用户须已登录。

验证：Windows 实机对照中，旧桌面权限的空操作包返回错误 5，补齐权限后被接受；生产函数的原生回归覆盖同名桌面权限升级、重复同步及不降级，输入单元回归 11 项通过。对照和回归仅发送不含鼠标动作标志的包，没有键盘、点击、移动或确认管理员请求；实际管理员窗口的交互结果仍需实机操作验收。
