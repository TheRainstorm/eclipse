# v0.20.4

修复 Windows 原生 D3D 合成在进入全屏、调整窗口或改变 DPI 后可能出现的黑屏、黑色菜单和 HUD。解码与 Present 仍在运行时，也可能因 OpenGL 的 UI 共享图层尚未完成而呈现错误内容。

现在实际重绘 UI 图层后，先完成 GL 写入，再解锁交还 D3D 采样。复用缓存 UI 的视频帧不执行这次等待，继续使用原有的原生视频合成路径。此修正可能增加 UI 重绘帧的同步时间，不能据此声称端到端延迟下降。

生成画面回归增加全屏进入/退出与混合 DPI 检查，并将像素检查绑定到被检查帧的 DPI，避免用下一帧的 DPI 解释旧帧。生成图验证不等于真实桌面、物理 HDR 或输入跟手感验收。

更新客户端后退出旧串流窗口，再打开新版生效。共享端无需因本次客户端修正而重启。

验证：170 项 GUI 回归通过（3 项隔离测试默认忽略），Windows 全目标编译检查通过。在实际 Windows GPU 上，以生成视频和 UI 逐像素检查全屏进出、隐藏恢复、缓存复用及 1.5×/1× DPI 切换，12 帧正式回归及另一次 120 帧扩展检查均通过。这不替代实际串流画面的用户验收。
