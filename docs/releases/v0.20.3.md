# v0.20.3

修复 HUD 已显示的持续停图在失焦、切换设备或改变帧率后可能丢失的统计错误。暂停时保留最近一次前台已观测到的停图记录和等待长度，继续按 60 秒窗口过期；后台时间不累加，恢复后也不重复计数。未观测到的后台间隔仍不计入。

这项修正由客户端更新后重开窗口生效。共享端可继续使用 v0.20.2 的采集节拍；完整操作延迟、主机跨度及长间隔的测量边界见 [HUD 说明](../hud.md)。

5 项连续性回归、全部 290 项核心回归、170 项 GUI 回归及 Windows 全目标编译检查通过。覆盖已观察停顿的暂停保留、帧率切换、恢复去重、窗口过期与未观察后台间隔的排除；GUI 三项显式隔离测试默认忽略。
