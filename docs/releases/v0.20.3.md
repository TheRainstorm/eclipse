# v0.20.3

修复 HUD 已显示的持续停图在失焦、切换设备或改变帧率后可能丢失的统计错误。暂停时保留最近一次前台已观测到的停图记录和等待长度，继续按 60 秒窗口过期；后台时间不累加，恢复后也不重复计数。未观测到的后台间隔仍不计入。

切换串流标签时立即暂停原会话的观察，不依赖后台页面再次绘制；窗口在两次绘制之间失焦又恢复时，也保留这次暂停边界，避免把后台等待记成卡顿。

这项修正由客户端更新后重开窗口生效。共享端可继续使用 v0.20.2 的采集节拍；完整操作延迟、主机跨度及长间隔的测量边界见 [HUD 说明](../hud.md)。

5 项连续性回归、全部 290 项核心回归、170 项 GUI 回归及 Windows 全目标编译检查通过。另在独立 Xvfb 中显式执行双路加密生成视频与真实窗口测试，覆盖切换标签时立即暂停观察、排序、拆分窗口和独立关闭，媒体 epoch 保持且解码错误为零。GUI 三项显式隔离测试默认忽略；这些检查不代表真实桌面或物理操作延迟已经验收。
