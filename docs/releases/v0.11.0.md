# v0.11.0：蓝白设置页面与更自然的悬浮菜单

本版本在 [v0.10.0](v0.10.0.md) 的串流与协议能力上完善桌面操作和局域网配置。

- 全屏悬浮入口默认贴右边缘、距顶部 15%，继续支持自由拖动与四边吸附。按钮由 36 点缩至 30 点，白色面积减少约 30%；菜单行距和留白同步收紧。
- 悬停立即展开，移出立即收起；点击交互后离开或窗口失焦 2 秒收起。主菜单和子菜单间可连续移动，编辑文本时保留焦点；视觉收起计时不阻塞已经交回远端的输入。
- 光标显示只保留“本地和远端光标”与“仅远端光标”，Ctrl+Alt+C 在两者间切换。旧的仅本地设置迁移为双光标。桌面绝对定位与游戏相对移动仍是独立选项。
- 应用设置改为独立页面，分为画面与显示、声音、键盘与鼠标、网络与共享、应用与诊断；支持返回设备或串流、未保存草稿、固定保存栏，窄窗口切为顶部分类导航。
- 主页、设置页、对话框和串流菜单采用统一的蓝白配色、文字层级和控件状态。原生界面保留本机中文字体，不下载外部字体。
- Eclipse 的 TCP 服务端口、UDP 发现端口可配置并持久保存；自动发现使用配置端口，并返回主机实际服务端口。共享期间端口保持不变，更改前需停止共享。
- TCP 监听冲突显示端口、系统原因和解决提示；修复后台线程快速结束时最终错误可能丢失的问题。UDP 发现冲突明确提示自动发现不可用，保留手动连接。错误提示前置，小窗口可以滚动查看。

Windows 原生 CI 增加设置迁移、主题对比和真实回环 TCP/UDP 冲突检查。界面检查使用隔离桌面与生成画面；串流输入与现有低延迟配置沿用原规则，未重新宣称完整端到端延迟已测得。

说明：[界面设计](../ui-design.md) · [局域网端口与配对](../native-lan.md) · [Windows 延迟](../windows-latency.md)。原生主机编码及网络能力的已知限制见 [0.10 说明](v0.10.0.md)。
