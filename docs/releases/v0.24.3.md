# Eclipse v0.24.3

本版本整理设备管理与详情页，增加分页连接历史、壁纸缓存和串流使用统计。通过 GitHub CI 提供 Windows x64、Linux x86_64 完整包及 `SHA256SUMS`。

## 设备管理与详情

- 单台设备右键菜单集中连接方式、串流配置、刷新、详情和移除；列表空白处提供添加设备、附近设备、批量管理、壁纸和本机串流测试。
- 串流配置支持选择默认或已保存配置，以及编辑、新建、复制和管理；编辑默认配置会进入应用设置，命名配置仅用于当前设备。修改影响下次连接。
- 批量管理改用右下角浮动图标按钮，设备卡片显示选择状态，并在浮层确认批量移除。移除只忘记本地记录。
- 详情页居中显示预览和概览，宽窗口使用有独立间距的双栏，窄窗口改为单栏；地址左对齐，配置操作统一靠右，身份信息默认折叠。更多菜单采用绘制图标，避免字体缺失时显示方框。

## 连接历史、壁纸与统计

- 服务管理的连接历史改为独立页面，仅显示已结束记录，每页20条，保留最近200次记录。服务更新进度放在服务状态右侧。
- 成功刷新的壁纸原图缓存在程序旁 `wallpapers/cache`，按内容去重并保留最近100张；启动继续先显示已有图片，收藏目录独立保留。
- 软件获得输入焦点、处于设备列表且没有编辑文本时，按F5刷新壁纸。
- 列表空白处右键可打开串流统计，查看累计时长、各设备时长与粗略里程碑。同一工作区的同设备多屏只计一次，不同设备的时长相加；本机回环测试不计入。

## 更新与验证

退出旧窗口和托盘，再用完整包更新，保留配置与配对；主程序、共享SDK和运行库需一起更新。具体连接插件仍独立分发，须匹配本版SDK。

相关设备工作区交互29项、Windows全目标编译、生成界面预览及完整包来源、SDK和内外校验检查通过。生成预览与状态测试不代替所有实体桌面、多屏和长期使用场景的实机体验。
