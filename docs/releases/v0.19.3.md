# v0.19.3

支持定制串流客户端快捷键，并将 HUD 悬停详情改为中文紧凑十行。

- 悬停详情按画面、帧率、延迟、网络、排队、恢复累计、异常累计、输入、收包、恢复原因排列，每类一行并着色。限制在当前串流客户区内，小窗口换行、内部滚动，避免非全屏时内容被裁切；主 HUD 保持英文。
- 输入设置中点击组合重新录入，可增加、移除或恢复默认，每项最多三个绑定。支持 Ctrl、Alt、Shift、Win/Super，按 Esc 取消录入。
- 重复组合标红并指出操作，冲突不能保存。Windows 的 Ctrl+Alt+Delete 不允许配置；可能被系统占用的组合显示警告。“内部无冲突”不保证其它应用不抢占。
- 当前串流、默认配置和设备命名配置分别保存，旧配置沿用原默认值；菜单、声音按钮、HUD 的提示随绑定更新。
- 录入拥有完整按下、重复和抬起，避免录入结束串流组合时误断开；更改绑定释放旧输入，按住的组合先松开再按新配置处理。
- 嵌套透传时，仅配置的“嵌套快捷键透传”操作始终由本机切换，不再固定保留 F12；该操作必须保留一个绑定。右 Alt / AltGr 留给远端输入。

[操作与保存范围](../keyboard-shortcuts.md)。真实桌面录入、系统快捷键与嵌套串流效果仍需安装后验收；平台和其它应用对快捷键的占用无法统一枚举。

验证：核心 346 项、GUI 161 项通过，3 项原有平台或隔离检查保持跳过；320×180、640×360、1280×720 窗口布局通过，640×360 的生产 HUD 模块在自有 Xvfb 完成实际渲染。未代替用户真实桌面的效果与按键验收。
