# uu-client 0.6.0 · 日常客户端体验与配置恢复

完善设备导航、配置异常反馈、版本核对和跨平台画面颜色，保留0.5的默认连接配置、原生剪贴板和双平台分发方式。

## 设备与窗口

- 新增收藏和最近使用筛选；最近使用记录打开或聚焦过串流窗口的设备，不代表已经成功连接。按账号分别保存，只记录设备标识，不保存令牌、名称或预览图片。
- 收藏或搜索变化后更新当前选择，避免操作已被筛选隐藏的设备；小窗口使用紧凑筛选入口。
- 修正浅色主题初始化次序、设备标题位置和筛选后的导航栏高度。
- 修复Linux X11窗口已销毁时仍查询坐标导致的崩溃；独立窗口生命周期回归加入CI。

## 配置与升级

- 本地账号文件损坏、超过1 MiB或无法读取时显示具体提示，保留原件，不自动重新注册覆盖。检查配置后可重试；已有串流不因短暂读取失败自动退出。
- 设置文件限制64 KiB。异常时使用内存默认值，HUD与音量等自动保存会拒绝覆盖原件；设置面板提供明确的备份后保存操作。备份失败时保留原文件，Unix备份权限为0600。
- 设置的保存、恢复和状态提示整体可滚动；关于页面适应较小窗口和较长构建说明。
- 关于页面优先显示程序编译时的Git提交号，并注明本地源码修改；安装清单不一致或损坏时提示。源码归档构建不借用外层仓库的版本。复制版本诊断不包含本机程序路径和账号信息。

## 色彩与解析

H.264范围和BT.601 / BT.709矩阵解析不再依赖Linux VA-API，Windows和纯软件构建同样读取VUI。共享SPS解析支持缩放列表，正确处理不同色度格式和隔行画面的裁剪单位；对循环、尺寸运算和SPS大小设置边界。

验证使用合成画面生成的Baseline/Main/High SPS，并与独立Chromium解析器比对。Linux无VA-API构建和Windows实机均通过真实OpenH264码流检查；Windows CI增加相同的纯CPU探针，不采集工作桌面或操作输入设备。

## 安装与边界

下载本版本双平台包并校验`SHA256SUMS`。Windows解压后运行`install.ps1`，Linux运行`python3 install.py`。升级保留账号、偏好和本地覆盖配置；正在运行的旧窗口需要重新打开才会使用新程序。

原生Eclipse仍为局域网、单控制端、单显示源的软件H.264串流，支持1–60 FPS。硬件编码、运行中切屏/画质、Wayland portal和公网发现继续按[远景计划](https://github.com/TheRainstorm/uu-client/blob/master/docs/vision.md)推进。没有新增H.265/AV1/HDR或视频RS FEC支持。
