# Eclipse v0.24.9

## Windows 后台与虚拟显示器

- 后台传输诊断写入服务配置的状态目录。更新、重新部署和重启时，服务权限检查支持 Windows 长路径。
- Windows 完整包的 Cargo 产物按工作区隔离，避免共用缓存时混入实验编译的编码器。
- Eclipse 虚拟显示器可与已有的单屏 MTT 驱动共存。保存已生效的分辨率和刷新率时保留 Windows 的显示器布局。
- 启动器在后台读取设备簿，减轻主页轮询造成的卡顿。

## Linux 显示与解码

- Wayland 下依据当前串流窗口的实际输出条件协商 HDR10。支持的硬件和图形环境可直接呈现 HDR，普通 SDR 输出继续使用色调映射。
- VAAPI 交付解码图时保留位深和可见区域，支持的 EGL 设备可直接导入 NV12 和 P010 表面。解码复用表面池，支持 AV1 流中序列尺寸变化及 H.264 受限基线码流。

## 串流性能与诊断

- AV1 RTP 组帧减少临时分配，视频收包复用缓冲，SRTP 复用同一媒体源的防重放检测器。
- Intel oneVPL 只清理 NV12 编码表面的对齐区域，减少多余的写入。
- HUD 区分原始视频缺包与恢复后的丢包。Linux 可查看当前串流套接字的内核丢包与接收缓冲。
