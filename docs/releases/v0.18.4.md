# v0.18.4：设备卡片与 Windows 首连修复

- 去掉设备截图上的“在线”“离线”“状态未知”角标，仅通过设备卡片变灰表示已确认离线；在线检测和右键刷新保留。
- 离线设备名称继续显示为有对比度的灰色，壁纸上增加文字阴影。名称按实际换行高度预留空间，长名称不再被固定高度裁掉；离线卡片仍可连接和编辑。
- 修复 Windows 高 DPI 后台主机首连可能报 `native host ended before delivering video`：在创建 DXGI 工厂前按物理像素枚举显示器，避免协商的逻辑尺寸与实际采集纹理尺寸不一致。主机日志保留串流运行失败的原始错误及不一致的具体尺寸。

包含 [v0.18.3](v0.18.3.md) 的 Windows 管理员确认及锁屏桌面输入修复。更新客户端即可应用主页显示；安全桌面输入修复仍须在被控端更新后台程序并重连。
