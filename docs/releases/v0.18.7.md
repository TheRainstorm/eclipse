# v0.18.7 测试版：输入菜单与 HDR

- 串流悬浮设置的“输入”集中提供光标显示、指针移动和手柄设置。新增隐藏光标，支持快捷键切换与保存；原生连接可显示或隐藏本机光标，尚未支持的远端光标合成明确禁用。
- Windows 原生串流支持 HDR10：浮点桌面采集、P010、AMD AMF / 支持的硬件 MFT 10 位编码、P010 硬解与浮点 scRGB 呈现。HEVC Main10 与 AV1 需经过实际解码探针；H.264 和不能显示 HDR 的客户端使用 SDR。
- “画面”增加优先 HDR 开关和实际 HDR/SDR 状态。HDR 桌面输出 SDR 时先做亮度映射；HDR 窗口的 SDR 菜单使用系统白色亮度。

两端及 Windows 后台服务均需更新完整安装包。为实际串流显示器和客户端显示器启用系统 HDR 后重新连接，详见 [HDR 说明](../hdr.md)。Linux 当前仍使用 SDR。此版先提供测试包，未创建正式 Release；显示器上的颜色与实际桌面延迟仍需实机验收。
