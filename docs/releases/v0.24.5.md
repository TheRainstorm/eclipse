# Eclipse 0.24.5

本版改进桌面采集恢复、多客户端输入及 Linux 主窗生命周期，修复 Windows 首次安装与虚拟显示器准备问题，并增加 Wallhaven 壁纸来源。

## 串流与输入

- Windows 共享采集在桌面暂时不可用时暂停并恢复，保留已有连接；没有首图的 SDR 桌面可使用实时兼容采集，并继续探测 DXGI。
- 保留采集失败的实际原因，不再把首图超时连续误报为所有视频格式均无法编码。
- 多客户端按实际活动取得键鼠控制权。上一方松开所有键和鼠标按钮、空闲约半秒后可交接；手柄保持独立，不因键鼠交接换代。
- Wayland 等待合成器新图时保留待完成的采集请求及未变化输出的输入，减少闲置后恢复操作时的额外等待。明确失败后重建，恢复直接交付有效新首图。
- 诊断日志补齐采编底层错误、输入可用性、映射状态、争用计数及排队和注入耗时，便于区分输入暂停与网络问题。

## Windows 主机

- 可通过本机或 RDP 登录桌面安装主机服务和同步插件；服务归属保持为发起操作的用户，采集仍共享物理控制台。
- 首次安装显示“未安装”，避免误报正在使用其它配置。
- 虚拟显示器管理分别说明远端能力、授权和通道状态；准备期间统一限制保存、删除等操作。
- 无显示器控制台枚举时过滤缺少监视器接口的强制占位路径；首次驱动确认在当前登录桌面完成。

## Linux 与壁纸

- Linux 主页可关闭到托盘并继续共享，再次启动程序会唤回同一配置的原窗口；托盘“退出 Eclipse 并停止共享”明确结束共享。
- 托盘注册成功后才隐藏主窗，托盘失效时恢复可见入口。支持 XWayland 的桌面用它承载需要隐藏的主窗，串流窗口及采集保持原生 Wayland；不支持隐藏时保留窗口与共享。
- 提供 Linux 卸载工具，以及可交互输入或通过标准输入设置配对密码的脚本。
- 增加 Wallhaven 壁纸来源，可选择榜单、热门或最新页面，并设置分类及 SFW、Sketchy 筛选。

## 连接准备与发行

公网候选发现与媒体准备并行，STUN 在总期限内重试，WSS 小消息启用低延迟 TCP；保留直连优先及 TURN 回退。更新两端后生效，连接耗时仍取决于网络与硬件。

GitHub CI 先统一检查源码、版本标签和发行说明，再构建并验证 Windows/Linux。修复浅检出缺少发布标签的问题，同一正式发布提交只运行一套完整双平台验证，并保留桌面失败的阶段诊断。RC 后续仅本地构建验证。

## 下载与更新

- Windows：`eclipse-windows-x64-v0.24.5.zip`
- Linux：`eclipse-linux-x86_64-v0.24.5.tar.gz`
- 校验和：`SHA256SUMS`

使用完整包更新，保留配置；退出旧窗口和托盘后再打开新版。Windows 被控端还需完成主机服务更新。共享 SDK 与运行库应随完整包一起替换，独立插件需要匹配本版 SDK。
