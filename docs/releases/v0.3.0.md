# uu-client 0.3.0 · 原生桌面共享与键鼠控制

原生局域网通路从观看扩展到显式授权的桌面控制。两端使用本项目即可共享显示器，不需要 UU 账号或第三方服务签名密钥。

- 主页增加“共享此设备”：选择显示器、本机网卡地址、帧率、码率和新邀请路径，界面显示等待、建立与串流状态；默认只读。
- 主机勾选许可后，受邀端可申请键鼠控制；桌面绝对定位、游戏相对移动、鼠标中键与标准 HID 键盘映射。Windows SendInput 与授权 X11 XTest 后端均不提权。
- 控制心跳、5秒失联租约、有界输入队列与独立释放请求，减少断线或拥塞后的按键残留；仅释放本会话成功按下的键。
- 悬浮菜单切换仅观看、重新请求控制；不支持的远端光标选项隐藏，使用本地光标。保留全屏、HUD、退出与释放键鼠快捷键。
- 停止共享或关闭主窗口先结束主机，会话结束后清理自己生成的邀请；不会覆盖已有文件或清理被其它程序替换为不同内容的文件。
- 修复无音频原生会话切换 HUD 时覆盖兼容模式静音偏好的问题。
- 新增隔离 Xvfb 的真实输入、加密视频、长按心跳、只读切换与断线释放检查，Windows 输入字段测试纳入 CI；与 v0.2.0 双向视频互通。

## 开始使用

Windows 下载 ZIP，解压运行 `install.ps1`；Linux x86_64 下载 tar.gz，解压执行 `python3 install.py`。先退出旧客户端，下载后可用 `SHA256SUMS` 校验。安装器保留本地账号与偏好。

主机选择“共享此设备”，跨设备时填写**主机自身的局域网地址**；默认回环地址只允许本机连接。将生成的 `.eclipse-invite.json` 私下传给控制端，再打开“使用原生邀请”。邀请等同本次访问许可，不要公开上传。详见[原生串流说明](https://github.com/TheRainstorm/eclipse/blob/master/docs/native-streaming.md)和[输入控制说明](https://github.com/TheRainstorm/eclipse/blob/master/docs/native-input.md)。

## 范围

原生模式当前为单控制端、单显示源、软件 H.264 编码（1–60 FPS）。Windows DXGI / 授权 Linux X11 可作为主机，Wayland 可作为观看与控制客户端；尚无 Wayland portal 采集、原生系统音频、剪贴板、运行中切屏/画质、跨公网连接或无人值守管理。窗口源和合成画面不允许桌面键鼠控制。键盘按远端布局解释，不含完整 IME 文本注入与消费设备页。

UU 兼容模式继续保留，须自行配置有权使用的本地连接凭据；发布包不含第三方生产密钥。Linux 包基于 Ubuntu 24.04，需兼容 glibc 与图形/音频库；Windows 包未做 Authenticode 签名。原创代码采用 MIT OR Apache-2.0，第三方组件保留原许可。本项目非官方，兼容接入的协议与知识产权风险详见仓库说明。
