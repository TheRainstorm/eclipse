# Eclipse 0.24.4

本版加入以服务端为中心的会话控制、共享游戏厅与悬浮球，并改进多客户端串流和窗口行为。

## 会话中心与游戏厅

- 在“服务管理 → 会话”或托盘右键打开悬浮会话中心。平时收起为可拖动的悬浮球，显示连接人数；点击展开，收起或关闭不停止服务及串流。
- 每个会话可分别授予键盘、鼠标、手柄权限，切换当前采集显示器、调整帧率和码率，或从更多菜单断开。画面参数默认折叠，操作失败保留原因。
- 开启“共享游戏厅”后，新加入会话默认仅观看，由房主逐项授权。已连接会话保持原权限，可用“全部仅观看”统一收回。关闭游戏厅不会扩大已有会话权限。
- 默认本机键鼠优先：Windows检测到物理键鼠操作时暂停远端键鼠，释放长按并丢弃暂停期间的旧输入；本机停止操作3秒后自动恢复。手柄独立运行，也可手动暂停或恢复键鼠。
- 游戏厅内由服务端管理画质和切屏；普通模式仍允许客户端调整自己的画面。会话权限始终受设备长期授权上限约束。

## 多客户端与窗口

Windows多个客户端观看同一物理显示器时共用采集源，各自保留独立编码、帧率、码率和传输。关闭一个客户端不影响其他订阅；手柄控制不占用唯一键鼠租约。

老板键只隐藏和恢复串流窗口，Eclipse主窗口、服务管理及会话中心保持原样。恢复保留原有隐藏、最小化和全屏状态，只向选定串流窗口请求前台焦点。另修复Linux界面首次绘制时的激活令牌锁重入。

## 更新与范围

退出旧窗口和托盘后，使用对应平台完整包更新；主程序、共享SDK及运行库需一起替换，并更新被控端主机服务。保留原配置和配对，连接插件仍独立分发且需要匹配本版SDK。

悬浮中心是普通桌面窗口，没有独立的远程点击隔离。显示器控制指切换当前采集源，尚无显示器准入白名单；面板运行时画质控制为帧率和码率。物理输入优先自动检测当前仅Windows可用，其他平台仍可手动暂停。

本地GUI回归、Windows编译及独立桌面窗口验证已通过；生成界面、状态测试和CI不能代替全部实体桌面、手柄及混合HDR场景的验收。正式Windows/Linux完整包和校验和由GitHub Release提供。
