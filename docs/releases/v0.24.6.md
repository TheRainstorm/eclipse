# Eclipse v0.24.6

本版完善 Windows 主机隐私、持久虚拟显示器与壁纸浏览，并修复后台更新和本机输入检测。

## Windows 主机与隐私

- 服务管理的“会话”中增加串流结束后的锁屏策略：默认恢复第一条连接前的锁定状态，也可选择不锁屏或始终锁屏。
- 多个客户端、多个屏幕共用一轮状态，最后一个会话结束才处理；异常断线保留 10 秒重连时间，失败重连不延长原倒计时。
- 串流菜单“安全”中增加“锁定远端”和“锁定远端并断开”，需要当前会话的键盘权限。系统确认锁定后才执行后者，失败或结果未确认会保留连接并提示。
- 修复本机物理输入检测缺少 Windows 钩子权限而长期不可用的问题，初始化或桌面切换失败后可以恢复重试。
- 增加“打开软件时自动启动后台服务”的独立开关，区分启动已有服务与安装、更新服务。
- 修复后台更新后，已启用插件尚未创建私有数据目录导致同步失败的问题。没有插件清单的旧目录不再误报为损坏插件，真实的清单或程序文件错误仍会显示。

## 虚拟显示器

- 正常启用的持久虚拟屏在退出程序、停止或更新服务后继续保留，只有手动禁用或删除才断开；临时屏保持自动回收。
- 下次启动接管原设备，活跃且模式相同则不重建、不重放布局。Windows 尚未枚举设备时等待恢复，避免删除重建造成闪断。
- 多进程接管仍检查设备归属和实际占用，不影响其它程序的显示器。

## 壁纸与快捷键

- 必应每日壁纸内置，无需启用插件；可以从今日向往期浏览、返回更新日期或直接回到今日，近期范围以接口实际可用内容为准，通常最多约 15 天。
- 随机来源支持回到之前看到的原图，回退后向前先重放已有历史；浏览历史时自动刷新不会跳走。历史保留当前运行及当前来源/筛选的最多 100 张，压缩图总量限制 64 MiB，磁盘缓存与收藏独立保留。
- Pipw 二次元与 Wallhaven 合并为可选的 `wallpaper-collects` 壁纸合集插件，默认关闭；Wallhaven 按榜单、热门或最新的接口顺序分页浏览并去重。
- F5 下一张壁纸、F6 上一张、F8 显示或隐藏设备列表；仅聚焦主页且没有编辑文字时响应，右键菜单右侧显示快捷键。

## 下载与更新

- Windows 完整包：`eclipse-windows-x64-v0.24.6.zip`
- Linux 完整包：`eclipse-linux-x86_64-v0.24.6.tar.gz`
- 可选壁纸合集：`eclipse-plugin-wallpaper-collects-x86_64-pc-windows-gnu-v0.24.6.zip`、`eclipse-plugin-wallpaper-collects-x86_64-unknown-linux-gnu-v0.24.6.zip`
- 校验和：`SHA256SUMS`

使用完整包更新，保留配置；退出旧窗口和托盘后重新打开新版。Windows 被控端还需更新实际后台服务，仅替换客户端文件不会改变旧服务的行为。壁纸合集下载对应平台附件并解压到软件目录，在插件设置中启用；UU 插件仍由独立仓库分发，须匹配本版 SDK。

Windows 真实桌面的锁屏、输入优先和显示连续性仍需按自己的使用场景验收。进程被强制终止或电脑断电时，应用无法保证执行退出锁屏处理。本版不包含此前暂缓调查的持续鼠标延迟问题修复。
