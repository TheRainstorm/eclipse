# v0.18.6 测试版：连接、采集与显示器切换

本版正在测试，尚未打标签或发布正式 Release。

- Windows 主窗口改用 Direct3D 12 呈现，处理部分 OpenGL 驱动绘制、交换均返回成功却没有界面内容的问题。
- 主页与隐藏协调窗口不再继承串流的垂直同步设置；隐藏协调窗口使用非阻塞呈现。
- 可见串流窗口继续按用户设置单独控制垂直同步。
- 修复 Windows 首帧后断开：按 DXGI 元数据区分桌面图像更新和仅鼠标更新，避免将鼠标通知中的不同格式纹理当作视频帧。
- 支持原生采集协议的 Wayland 合成器直接共享指定显示器，不再每次连接都等待系统选屏；列出真实显示器名称与尺寸。其它桌面继续使用系统门户授权。
- 服务器显示器设置改为选择初始画面，客户端默认可以切换显示器，不再需要单独选择“允许远程切换显示器”。
- 切换显示器保留串流中已应用的帧率和码率；原生 Wayland 画面按显示器方向映射。

包含 [v0.18.5](v0.18.5.md) 的连接进度与取消修复。客户端与被控端均需更新完整安装包并重开主程序；Windows 后台采集修复需更新后台程序后重连。门户桌面的屏幕选择仍遵循系统授权要求。
