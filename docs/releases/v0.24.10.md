# Eclipse v0.24.10

## 连接与诊断

- TURN 服务器连接支持自动、强制直连和强制中转。自动模式优先尝试直连，失败后使用中转。
- 命令行可探测 UDP NAT 映射及可验证的过滤行为。串流诊断可查看实际选中的连接路径。
- HUD 的 BW 显示当前显示器的实测视频码率。服务管理显示当前后台与待更新版本的提交编号。

## Windows 虚拟显示器

- 经过认证的 Windows 无头主机可用已安装的驱动临时创建显示器，在最后一路使用它的会话结束后回收。
- 保存虚拟屏的分辨率、刷新率或 HDR 设置时保留该屏的身份。支持模式续接的客户端在源分辨率变化后重新准备画面。
- 从 Windows 手动卸载的 Eclipse 虚拟屏可从原定义重新启用。启用时等待新屏报告请求的显示模式，保留名称和规格。
- 「驱动与诊断」提供普通安装和清理重装。清理重装移除当前配置的 Eclipse 自建屏及保存的设置。若某路会话正在使用将被移除的屏或其复制屏，界面会指出受影响的客户端。
- 默认控制授权包含虚拟显示器管理。已细分的设备授权沿用各自设置。

## 窗口与串流

- 普通连接在初次协商时优先选择上次使用且仍可用的显示器。
- 窗口模式支持用 Ctrl+Alt 方向键切换串流显示器或设备。Windows 拖动或缩放窗口时，重绘让鼠标移动先处理。
- 串流菜单可调整「退出当前串流后锁屏」。被控端在最后一路会话结束后根据本次选择和主机策略处理锁屏。
