# Eclipse 0.24.5 RC1

本候选版修复 Windows 首次安装问题，并改进自建连接服务的准备过程。预发布标签为 `v0.24.5-rc.1`，当前稳定版仍为 0.24.4。

## Windows 服务

- 允许从本机或 RDP 登录桌面安装和同步插件，服务归属取发起操作的登录用户；UAC 使用另一管理员账号时保持原用户归属。后台采集仍运行在物理控制台，RDP 安装不会切换共享目标。
- 尚未安装服务时明确显示“未安装”，不再误报“正在使用其它配置”或要求结束不存在的串流。首次通过托盘启用也会进入安装流程。
- 已知不同配置仍需明确切换，不能读取归属时继续保留管理写入限制。

## 自建连接准备

公网候选发现提前启动，与等待媒体请求、采集和编码准备并行。STUN 丢包后按指数间隔重试，所有尝试共用原有总期限；WSS 小消息启用低延迟 TCP。媒体应答仍等待完整候选和实际编码验证，保留直连优先及 TURN 回退。

请更新客户端和被控端，并更新 Windows 主机服务。改进不需要更换接入码。公网生成图和相关回归已通过，实际连接耗时仍取决于两端网络及硬件；曾出现的三十秒连接场景仍需实机复测。

## 下载与更新

- Windows：`eclipse-windows-x64-v0.24.5-rc.1.zip`
- Linux：`eclipse-linux-x86_64-v0.24.5-rc.1.tar.gz`
- 校验和：`SHA256SUMS`

Linux 解压目录同样使用版本标签。包内清单保留完整源码提交、运行库身份及文件摘要，下载工具核对标签和内部来源；此前使用提交号命名的正式包仍可下载核验。本地开发包继续使用提交号区分。

使用完整包更新，保留配置；退出旧窗口及托盘后重新打开。包含共享 SDK 的运行库需一起替换，独立插件需匹配本版 SDK。
