# Eclipse v0.24.1

本版本完善设备与壁纸页面、全窗口老板键及主机管理，并修复经路由器端口转发的 IP 串流。完整包与校验和见 GitHub Release。

## 设备、壁纸与设置

- 设备列表右键支持隐藏、恢复与管理；管理模式可多选删除和拖动排序，图标及文字大小可分别调整。
- 壁纸刷新可选择不刷新、每次打开或每隔指定小时刷新。
- 收藏图片不限数量，每页20张，按收藏时间倒序。页码从最早图片开始分组、从大到小显示，默认打开最新的最大页；增加图片保留旧页分组。
- 支持手工将标准图片加入数据目录的 `wallpapers/favorites`，首次扫描时间作为收藏时间；重复扫描保持时间，右键可删除，旧 `.image` 收藏迁移为标准扩展名。
- 关于页直接显示精确到秒的构建时间，保留复制版本信息。移除串流输入状态显示、设置中的虚拟屏规格入口及教程中的单机测试段落；本机只读测试入口仍保留。

## 全窗口老板键

- 默认 Ctrl+Alt+B 隐藏本机 Eclipse 的主页、串流及服务管理窗口，再按恢复原可见窗口，保留窗口身份、几何、全屏和连接。
- 隐藏前释放远端按住输入，视频、音频及后台服务继续运行。原本隐藏的窗口保持隐藏，Ctrl+Alt+D 仍独立控制串流返回本机。
- 多进程共享状态，快捷键持有者退出后可由其它窗口接管；录入快捷键期间暂停全局命令，录入结束后恢复。
- Windows 使用全局热键，Linux X11 使用桌面注册，Wayland 使用 GlobalShortcuts 门户；组合被占用或平台不支持时不隐藏窗口。

## IP 连接与主机管理

- 修复已认证入口返回主机内网媒体地址导致跨网连接超时。后续 TCP 与 UDP 使用已认证连接的实际主机地址，证书固定与授权校验保持。
- 支持被控端转发控制 TCP 端口及串流 TCP/UDP `49000–49009`、控制端处于 NAT/CGNAT 的连接。客户端主动发起 UDP 探测，主机从已认证 ICE 检查学习实际回程端口，不要求主机主动连回客户端；串流端口内外须一致，见 [IP 连接说明](../native-lan.md)。
- 连接超时区分 TCP、TLS 和串流授权阶段，便于定位问题。
- 连接服务按 IP 直连和自建服务器卡片组织，自建条目右侧可新增，保存、还原及保存并重启统一放在页底。
- 主机增加默认开启的 IPv6 选项；关闭后保留 IPv4。显式防火墙修复检查并补齐 IPv4/IPv6 覆盖，保持已有网络范围，不自动放开 Public 网络；系统查询预算与管理通道保持一致。
- 虚拟显示器采用配置列表与逐条启用、禁用、删除，固定最多16条；加号只添加配置，启用才创建 Windows 设备。按需物理增删、稳定命名、默认恢复合法布局或主屏右侧扩展，检查驱动后显示明确结果。
- 便携数据可保存在程序旁 `eclipse-data`；不同目录各有独立主机配置，Windows 同时只运行一个主机。迁移与切换说明见 [配置存储](../configuration-storage.md)。

## 更新与验证范围

请使用匹配的完整包更新程序和 SDK，再退出旧进程重开。主机功能还需更新实际 Windows 后台服务；只验证客户端 IP 地址修复时，可先更新控制端。独立原生插件必须与新 SDK 匹配。

本机回归覆盖核心及 GUI、真实 TLS 转发、加密媒体及 NAT 源端口改写夹具；自有 Xvfb 两进程四窗口验证老板键、长按抑制、原显隐与几何、退出接管及录入暂停。Windows 已完成全工作区全目标编译。隔离夹具不能替代 B→WYM 实网、实体 Windows 快捷键、Wayland 门户授权、虚拟屏 HDR 和长期稳定性的实机验收。
