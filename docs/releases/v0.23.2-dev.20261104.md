# Eclipse 0.23.2-dev.20261104

本开发版继续调整主题选择与主页设备列表，基于本地 v0.23.1 里程碑。开发包使用独立提交编号交付，不覆盖 v0.23.1 标签或既有安装包。

## 本轮范围

- 在“软件设置 → 外观 → 界面主题”中选择浅色、深色或跟随系统，保存后应用。新配置及缺少主题字段的旧配置默认浅色；已经保存的显式选择继续保留。主窗口、串流窗口和独立管理窗口沿用全局外观偏好，设备画质配置不覆盖它。
- 选择跟随系统时响应平台提供的外观变化；平台没有提供外观信息时使用浅色配色。
- 主页设备项恢复为截图与名称，截图使用6px圆角；点击截图或名称连接，右键继续使用详情、连接方式和配置管理。
- 已有设备的列表不再显示首次共享密码引导，空列表保留首次连接指引。

## 验证与更新

主题状态、显式偏好保存、旧配置迁移、过期客户端保存、跨窗口通知及设备点击/右键操作有定向验证。真实 Windows 系统外观切换和完整桌面体验仍待实机确认；生成预览不代替这项验收。

使用按独立提交编号生成的完整开发包，完全退出旧主页、托盘和独立串流窗口后更新主程序与匹配插件。本轮不要求为主题和设备主页调整重装驱动或更新后台。版本号改变会更新SDK身份，运行库与插件须使用同一完整包。本说明不表示当前已有对应正式发布。
