# v0.10.0-rc.1：Eclipse 局域网连接候选版

此版本进入原生局域网设备发现与持久配对阶段，供体验和验证。候选版不替换 v0.9.0 最新稳定发布，也不代表已达到 Moonlight / Sunshine 的性能与功能覆盖。

- 启动默认进入 Eclipse 局域网：自动发现主机，也可保存 IP / 主机名后手动配对，不需要第三方账号或签名凭据。原有账号设备入口保留在“兼容设备”。
- 主机明确启用共享和限时新配对；控制端显示八位配对码，主机输入核对后授权。以后点击已配对设备即可打开独立串流窗口。支持固定证书验证、地址变化检查、忘记本地配对及主机撤销授权。
- 共享窗口显示真实的采集准备、画面规格、编码后端与声音状态；可只断开当前串流并保留服务，正常退出会停止监听、媒体和待确认请求。
- 文本剪贴板默认关闭、双方许可。每次会话使用独立状态，离焦和退出停止同步，重连不残留上次待发送文本。
- 修复不同电脑系统时间有偏差时，刚签发的短期串流能力被误判过期。即时能力使用客户端单调截止时间，主机仍独立检查授权和有效期；不改系统时间、不延长服务端期限。
- 提供 `uu lan` 前台主机、发现、配对、查看、解码探针与撤销入口；独立进程回归接入 CI。GUI 空闲页减少重绘，活动会话与视频仍按事件即时唤醒。
- 合入 Linux H.264 硬解下载缓冲优化和实际解码后端 HUD。实验性 DMA-BUF / EGL 直接呈现须 `UU_GPU_VIDEO=1` 显式启用，完整硬件验收尚未完成；默认使用已验证的下载与平面呈现路径，保留垂直同步。

验证已覆盖 Windows / Linux 双向直连生成视频、发现、配对和保存后复连，含真实系统时间偏差。双方许可剪贴板使用加密通道和内存中的生成文本验证，不读取工作剪贴板；窗口流程在隔离桌面验证。CI 和这些检查不代替不同显卡、桌面及真实网络的长期体验测试。

已知限制：主机仍一次共享一个显示源、一个会话；运行中切屏和画质协商、Wayland 主机 portal、Windows 硬件编码、H.265 / AV1 / HDR、视频 FEC 及公网寻址尚未实现。Windows 主机使用当前交互会话 DXGI，Linux 主机使用 X11；Wayland 客户端可连接其它主机。新安装包保留原账号和设置，原生共享需手动启用。
