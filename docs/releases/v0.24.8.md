# Eclipse v0.24.8

本版重点改善 Windows Intel 主机的编码吞吐与静止文字画质，简化完整包安装和配置迁移，并修复画面设置、多路光标与跨 DPI 迁屏问题。

## Intel 编码与画质

- 兼容的 Windows Intel SDR 采集设备默认优先使用 oneVPL 同设备 D3D11 纹理输入，减少显存读回与重复上传。打开失败时继续尝试既有后端；用户显式关闭纹理输入或指定 MFT 调优时保留其选择。HDR 和其它厂商路径按各自能力处理。
- 修复 Intel AV1 CBR 静止文字在周期关键帧后逐渐模糊的问题。默认由驱动选择码控缓冲，保留 CBR 和低延迟异步深度；显式设置的 VBV 仍生效。
- 主机增加统一的低延迟编码参数：关键帧间隔，以及适用后端的质量/速度、VBV、队列与 AQ 等选项。参数按实际后端校验，不支持的显式组合会说明原因；更改后在后续媒体准备时应用。

在一台 Intel Arc 主机的固定离屏输入测试中，4K60 AV1 CBR 48 Mbps 达到约 60 FPS，修复后的两轮编码 P95 为 15.87 / 15.40 ms。1080p 静止文字长测和独立硬解验证确认笔画劣化已修复。这些结果衡量特定硬件上的编码与画质，不能换算为所有设备的串流显示延迟。[编码设置](https://github.com/TheRainstorm/eclipse/blob/v0.24.8/docs/guides/client-and-server-settings.md)

## 解压运行、插件与配置

- Windows 默认便携：解压完整包后双击 `eclipse.exe`，首次启动在程序旁创建 `eclipse-data`，无需先运行安装脚本。创建系统入口仍可使用可选的 `install.ps1`。
- Windows、Linux 完整包都自带匹配主程序 SDK 的 **UU 兼容插件**和**壁纸合集**，默认关闭；在“应用设置 → 插件”按需启用。壁纸合集提供 Pipw 与 Wallhaven，必应每日壁纸仍内置于主程序。
- “应用设置 → 常规 → 配置存储”支持迁移数据目录并重启，保留设备身份、配对、主机配置和持久虚拟显示器。迁移成功后原目录仍保留，不合并两份配置。
- 旧 Windows 用户目录可通过“使用旧版用户配置”显式恢复；程序记录精确目录，后续启动和串流子窗口继续使用同一份数据。新解压的独立安装保持独立，不自动采用其它安装的 AppData。
- 修复旧平铺配置迁移时重复复制状态目录的问题；服务部署失败会报告具体操作和文件路径，便于定位权限或缺失文件。
- Linux 完整包附 `uninstall.py`，支持与安装相同的 `--prefix`。普通卸载保留用户配置；`--purge` 清理默认用户配置及数据位置选择文件，外部自选数据目录仍保留。

[数据目录与升级](https://github.com/TheRainstorm/eclipse/blob/v0.24.8/docs/guides/configuration-storage.md) · [插件说明](https://github.com/TheRainstorm/eclipse/blob/v0.24.8/docs/guides/plugins.md) · [Linux 安装](https://github.com/TheRainstorm/eclipse/blob/v0.24.8/docs/development/linux-client.md)

## 设置、设备与窗口

- 帧率和分辨率的常用、其它预设、自定义编辑分开显示，避免嵌套下拉层过宽；增加更多预设，并保留自定义值和跟随本地模式。修复选中值被省略号遮住及自定义宽高换行的问题。
- 原生码率的推荐选项统一显示为“推荐码率（LAN Quality）”，标题与勾选一致；固定码率和兼容协议各自保留原有含义。
- 设备右键“串流配置”中，点击名称设置常用配置；同一行右侧“串流”按该配置启动一次，保留原来的常用选择。已连接时继续聚焦已有窗口。
- 修复 Windows 11 混合 DPI 显示器之间迁移主窗口、串流窗口时的几何处理，采用系统建议的目标矩形；Windows 10 保留原有兼容路径。

## 串流性能与诊断

- 共享采集统一调度各路帧率，在源帧周期内等待新图，减少静态画面的重复轮询；多路串流的光标订阅各自唤醒，避免相互覆盖。
- 复用 Windows D3D11 渲染目标视图，减少逐帧准备；缓存成功解析的进程配置，避免热点路径重复读取文件系统。
- AES-GCM RTP 加解密直接使用输出缓冲区，减少中间分配和复制，保留认证与重放保护。
- 增加真实 GUI 取图、转换、呈现和输入门禁的可选观测，以及可复现的动态图和鼠标负载工具；完善源图身份与统计边界，缺少证据时保留未知。

另提供默认关闭的 Windows 实验：绘制前取同源最新解码图，以及精确 2∶1 SDR 原生 GPU 融合缩放。它们需要明确开启并核对实际路径，不改变默认呈现队列。本版仍不承诺解决所有窗口模式延迟或偶发鼠标跟随问题。[实验与延迟口径](https://github.com/TheRainstorm/eclipse/blob/v0.24.8/docs/performance/native-latency.md) · [测量方法](https://github.com/TheRainstorm/eclipse/blob/v0.24.8/docs/performance/streaming-latency-profiling.md)

## 下载与更新

- Windows 完整包：`eclipse-windows-x64-v0.24.8.zip`
- Linux 完整包：`eclipse-linux-x86_64-v0.24.8.tar.gz`
- 校验和：`SHA256SUMS`

两端完整包均包含上述插件，无需另行下载；插件仍需手动启用。升级前退出旧窗口和托盘，保留 `eclipse-data`、`eclipse-profile.json` 及外部自选数据目录。使用旧 AppData 配置时按“配置存储”的恢复入口操作；不要直接把平铺数据覆盖到新的数据根目录。

Intel 编码、采集与主机参数改动需要更新被控端实际后台服务；窗口、设置和呈现改动需要更新控制端。正式资产以 [GitHub Release](https://github.com/TheRainstorm/eclipse/releases/tag/v0.24.8) 实际构建与校验结果为准，桌面交互和不同硬件的长时间稳定性仍需按使用场景验证。
