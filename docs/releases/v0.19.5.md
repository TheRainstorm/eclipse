# v0.19.5

HUD 详情增加最近三分钟的延迟曲线、逐项解释和复制操作；悬浮菜单统一样式，客户端快捷键统一由应用设置管理。

- 精简 HUD 先显示 Bandwidth 再显示 RTT，阶段写作 Enc/Dec/Rnd；移除主栏 net/que，保留预估总延迟。SDR 编码显式标注 SDR，包括 PyroWave。
- 中文详情将采集、编码、解码、渲染与网络、排队分组，每个数值可悬停查看含义。“链路丢包”保留修复前缺包，“修复后丢包”表示超时仍未恢复；二者不能混用。
- 右侧曲线记录当前连接最近三分钟，每半秒采样，可切换各阶段，悬停查看历史数值。未知数据留空，不补零；调整画质保留同一连接的历史，重新连接重新记录。
- 详情增加“复制详情”。点击详情后键盘归本地，可选中文字并复制；点击画面、Escape 或失焦后释放本地归属。
- 悬浮菜单使用一致的行高、留白、选中标识和悬停说明；未连接成功时也可调整偏好。编码模式和“更多 → 统计信息”均可悬停展开二级子菜单。
- 推荐码率优先显示计算值。UU 兼容模式的“原画”发送服务端质量档位请求，由服务端决定质量与码率，并非固定 30 Mbps；原生串流使用推荐值或手动码率。
- 客户端快捷键移到应用设置，所有串流窗口共用。旧全局设置自动兼容，设备画质配置不再覆盖快捷键；保存后更新已打开的新版串流窗口。

完整退出旧主页和串流窗口后重新打开。主机和客户端使用相同版本，可获得完整诊断信息。编译与生成图验证不能代替实际桌面的键鼠、显示器及视觉验收。
