# uu-client 0.9.0

这次主要减少客户端视频呈现中的额外处理，保留默认垂直同步。

- GUI 直接接收最新 NV12/I420/BGRA 平面，由 GPU 完成颜色转换与缩放，省去 CPU RGBA 转换、逐像素 ColorImage 和更大的 RGBA 上传。1080p NV12 每帧上传约 3.1 MB；原 RGBA 约 8.3 MB。纹理复用，失败时保留原路径。
- Windows 硬解读回复用有界 CPU 存储，省去逐帧大块分配与清零；最后一个图像读者释放后才归还，不外借 GPU 映射指针。着色器接口与固定采样器映射也移到初始化。
- Windows 使用 ICodecAPI 补齐内置 H.264 解码器低延迟设置，兼容属性接口不可用的情况；不支持提示时继续使用有效硬解。
- HUD 按 500ms 统计和显示，缓存排版；数字平稳、视频仍逐帧。Decode/Render 口径保持透明，GPU 读回尚未移除。
- 新增隔离 GL 颜色及上传对照测试，覆盖三个像素格式、四种颜色矩阵、行填充、方向、尺寸变化、纹理复用和 BGRA 未定义透明字节。Windows 测试仅在自己创建的非交互窗口站运行。
- 可使用 `python3 tools/release/download.py` 获取并校验已发布双平台包，无需本机 Rust 编译；统一写入 `artifacts/packages/`，不自动安装或启动软件。

源码 CI 必须通过完整工作区、独立 SRTP 回归、双平台构建及既有输入、剪贴板、音频、Wayland 隔离门禁。上传压测是生成像素的局部 CPU/提交测量，不作为官方客户端等效或端到端延迟保证。路径与复现范围见[延迟说明](../windows-latency.md)。
