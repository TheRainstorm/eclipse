# v0.19.0

实验性 PyroWave 原生串流，主程序保持 Rust，通过固定 C API 接入 Vulkan 运行库。

- 两端明确选择 PyroWave；默认自动编码、已有连接与 UU 兼容格式保持原有规则。
- Windows 接入 D3D11 / Vulkan 共享纹理和 fence；解码输出带槽位租约，完整画面保持在 GPU。
- Linux 提供明确标识的 CPU 上传/读回路径，支持格式互通与生成图复测。
- 当前范围为 SDR、8 位、BT.709 全范围、4:2:0、CBR 帧预算。HDR、4:4:4、VBR 与 Linux GPU 直接导入尚未实现。
- 复用原生加密传输与修复，增加有界分片、精确格式协商和码流校验；完整安装包包含运行库和许可。

RX 7900 XTX 生成图测量：1080p / 200 Mbps 编码完整调用 p50 约 0.74 ms；4K / 800 Mbps 约 1.70 ms。GPU 内核、CPU 提交和实际端到端延迟分开报告，条件与限制见 [PyroWave 支持说明](../pyrowave.md)。用户实际双机桌面验收仍待完成，正式发布以 GitHub Releases 上的实际产物为准。
