# v0.16.0：多设备工作区、远程服务管理与配对权限

包含 v0.15.1 的输入、自动编码、画质菜单、原生 AMF 及 CPU 输入资源修复。

- 新连接默认加入已有串流窗口，按设备管理显示器；支持排序、分离到独立窗口及迁移已有会话。各会话保留独立媒体、声音、HUD 和临时画质，关闭一个不会结束其它会话。
- 键盘捕获和输入归属于前台会话；切换、失焦、分离和关闭时释放旧输入。修复 Windows 隐藏协调窗口与本地会话迁移的生命周期。
- 客户端可在原连接内动态修改帧率和码率，删除服务器最大帧率、默认码率和最大码率设置。GUI 支持请求 5–240 FPS，仍校验格式和硬件资源限制；编码或分辨率改变需要重新协商媒体。
- 服务器运行和串流期间可编辑配置，保存供下次启动生效，也可保存并有序重启。获独立“管理服务”权限的客户端可编辑远端主要共享参数，并在收到保存回执后请求重启；提供配置版本冲突检查。
- 启动服务器默认接受新设备的配对申请，仍需认证与授权。支持配对码、密码、临时配对码、预授权公钥；临时授权断开失效。
- 共用四路媒体会话上限，按设备分别授权键盘、鼠标、手柄、剪贴板和服务管理。同一时刻一个输入控制者；修改权限会释放输入并断开受影响客户端，重连后生效。
- 已登录 UU 账号时，添加设备可从账号设备列表选择。
- 硬件参数提供 Windows AMD AMF 速度 / 均衡 / 画质、Intel oneVPL Target Usage 1–7 与低功耗模式、Windows NVIDIA MFT 画质 / 速度 0–100；检查实际应用值，驱动拒绝时明确显示请求组合。

## 升级与能力边界

- 设备配置升级到版本 5，读取旧版后首次保存前备份。降级前应保留并恢复旧版备份。
- 远程管理覆盖共享、采集、编码、声音、输入及端口 / 入口开关等。配对密码和预授权公钥仍在服务器本机管理；连接服务地址、令牌和证书不在远程编辑范围。
- Windows NVIDIA 目前使用驱动 MFT，未接入原生 NVENC 或 P1–P7，也没有 NVIDIA 实机验证。Linux VA-API 不支持 AMD / NVIDIA 自定义参数；Intel 自定义参数使用 VPL。
- AMD 九组参数实机通过；Intel 十三组中九组通过、四组被驱动拒绝，不保证所有参数组合可用。
- Windows 隔离实窗已验证双会话加入、排序、分离和单会话关闭；Win+V、真实嵌套桌面、跨 NAT 新配对与日常 4K 高帧率仍需目标环境验收。
- 本版不包含 v0.17 的突发参考帧队列、恢复统计和长会话日志轮转。视频 FEC、发送端包节奏、按需无限 GOP、HDR 未实现。

Windows ZIP / Linux tar.gz 及 `SHA256SUMS` 随本版提供。重启服务会结束现有串流；客户端之后重新连接。升级安装保留本地设置和授权，现有进程需关闭后重新启动。
