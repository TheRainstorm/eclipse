## 显示器切换

原生工作区首次访问另一显示器时建立对应连接，之后在已有视图间切换，不重新协商连接。拆窗和合并也保留该视图的控制器；切换已访问视图不重新调整窗口大小。

已访问的显示器会继续占用串流、带宽和解码资源，并计入被控端的并发容量。同一窗口中同设备的缓存视图只由当前视图输出声音，用户的静音和音量偏好保持独立。关闭相应视图或窗口可释放连接。首次访问、已断开的连接和被控端容量不足时仍需等待连接或处理错误。

新构建使用自己的本地工作区命名空间，避免新启动请求被升级前仍存活的旧工作区接收。旧串流可继续运行；同一构建的新连接仍加入自己的已有工作区。

## 垂直同步

默认 `Ctrl+Alt+V` 切换垂直同步，菜单显示实际绑定，可在设置中修改。旧自定义配置若已经占用这个组合键，会保留原绑定，并让新增动作暂不绑定。

Windows 原生 GPU 呈现将非阻塞准入检查前移到共享纹理锁和绘制之前。队列忙时继续处理界面与输入，跳过该次呈现并安排重试，减少在共享绘制锁上等待的机会。必要的纹理上传、窗口尺寸变化等仍可能耗时；此改动不保证固定毫秒数的鼠标延迟。
