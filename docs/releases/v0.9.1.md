# v0.9.1：Linux 硬解下载与低功耗客户端

Linux VAAPI 在低功耗处理器上可能出现硬解已生效、Decode 仍达十余毫秒的问题。此前每帧通过 VAImage 映射，部分 Intel 驱动会做平铺转换，并在解除映射时再次转回。现在对线性和普通 Intel Y 平铺 NV12 表面使用只读 DMA-BUF 下载，直接复制可见像素并复用 CPU 输出缓冲，减少转换和分配。

- 保留垂直同步、原有分辨率和画质设置。没有新增等待展示的帧队列。
- 每次读取遵守 DMA-BUF 同步协议，检查两平面范围、行距、偏移和裁剪；不改写解码参考表面。
- 未知、压缩或不支持的布局仍使用驱动 VAImage 路径，保留硬解；可用 `UU_VAAPI_READBACK=legacy` 做同机对照。这仍是 CPU 下载，不是 GPU 零拷贝。
- HUD 直接显示实际的 VAAPI / D3D11 硬解或 OpenH264 软解；回退原因保留在悬停详情。
- 会话日志增加实际分辨率、音频欠载、队列和丢弃信息，帮助定位 De 正常但 Rd 偏低或声音断续的问题。
- 仅观看且从未发送按键的窗口不再在焦点变化时发送修饰键释放。交互会话仍保留按键清理。

新增硬件对照工具逐帧比较新旧下载路径的元数据和全部可见像素。CI 提供 `linux-media-validation` 工具产物；硬件性能与桌面呈现仍需在真实设备验证。参见 [Linux 客户端说明](../linux-client.md)。
