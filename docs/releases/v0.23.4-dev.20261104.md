# Eclipse 0.23.4-dev.20261104

本开发迭代包含上一阶段的设备多配置、实际参数页和青蓝配色，并增加“动森”主题与独立 Rust 组件库。以独立提交编号交付完整开发包，不创建正式标签或 Release。

## 使用变化

- 在“软件设置 → 外观 → 主题配色”选择默认蓝、青蓝或动森；浅色、深色和跟随系统仍独立选择。默认浅色与默认蓝保持不变。
- 动森配色采用奶油纸底、棕色文字、薄荷强调色、胶囊输入与按钮、带按压反馈的主按钮、圆角卡片与开关；深色模式使用暖色夜间配色。
- 设备配置名称旁的下拉箭头加载已有配置；输入新的名称以当前参数另存。删除当前默认配置后使用全局默认，已建立的连接继续使用原参数。
- 画面与编码页直接展示实际设置，移除简化画质和视频兼容性预设，以及用于隐藏实际参数的高级设置折叠。

## 可复用组件

[animal-island-ui](../../crates/animal-island-ui/README.md) 是只依赖 egui 的独立 Rust crate，提供按钮、输入、选择器、开关、卡片、状态标签、标题和语义颜色。它不依赖设备、串流、配置或本项目国际化模块，可独立使用。运行 `cargo run -p animal-island-ui --example gallery` 查看交互示例。

组件参考 [guokaigdg/animal-island-ui](https://github.com/guokaigdg/animal-island-ui) 的设计规范，保留 MIT 许可；本地嵌入圆体字体的 OFL 许可也随包提供。中文沿用系统字体回退。此次实现覆盖应用使用的核心组件，未移植整个 React 库。夜间配色是本项目扩展。

## 更新与验证边界

使用完整开发包同时更新主程序、运行库与匹配插件，保留用户配置和配对。本轮界面功能不要求重装驱动或重启后台服务。

组件交互、配置状态和主题测试覆盖键盘、禁用与输入法事件等规则；生成图和普通单元测试不能代替实际 Windows 桌面操作验收。
