# uu-client 0.7.0 · 原生 Linux 硬件编码与桌面集成

原生共享增加实验性 Linux VA-API H.264 编码，让支持的 GPU 承担编码工作。UU 兼容模式的远端编码方式不受此功能影响，Windows 原生主机继续使用软件编码。

## 编码选择与恢复

- “共享此设备”提供软件、自动和 VA-API 选项；硬件选项只在启用 VA-API 的 Linux 构建中显示。默认仍为软件编码。CLI 使用 `native-host --encoder software|auto|vaapi`。
- 共享窗口显示实际后端。自动模式在硬件初始化或运行失败时回退 OpenH264，并从新的 IDR 参考链继续；显式 VA-API 模式失败时报告原因。非法参数在驱动调用前拒绝。
- 编码器在已验证邀请和媒体请求后准备，不自动修改主机显示器布局。驱动由专属线程管理，命令队列及等待时间有界。
- 恢复请求生成 IDR 和 SPS/PPS；每个强制恢复帧使用新的软件解码器冷启动检查。保持原生媒体协议 v1，与 0.6 客户端互通。
- 共享设置和运行信息在小窗口内可滚动，仍能访问停止共享。

合成画面在支持 VA-API 的 Linux 设备上完成 720p、1080p、竖屏和 4K 色彩、裁剪与恢复检查。720p 编码调用均值约软件 11.2 ms、映射上传硬件 3.4 ms；该数字包含转换、上传和等待，不代表端到端延迟。真实 LAN 硬件主机向固定 0.6 软件解码客户端传送 1,200 帧，解码错误为 0。详细范围见[编码后端说明](https://github.com/TheRainstorm/uu-client/blob/master/docs/native-encoding.md)。

## 本地诊断与 Linux 启动项

- 两种连接模式的会话诊断统一写入用户状态目录，不再优先写程序旁边，避免安装在共享目录时把新日志放到共享位置。Unix 新建目录为 0700、文件为 0600；已有旧日志保留，不自动移动或删除。
- Linux 生成与窗口应用标识一致的 `uu-client.desktop`，修正图标和任务栏分组识别；旧启动项保留为隐藏兼容入口。启动路径按桌面规则转义，直接启动程序，不经过 shell。

## 安装与限制

从本版本下载 Windows ZIP 或 Linux tar.gz，校验 `SHA256SUMS` 后运行包内安装器。升级保留登录态和偏好；正在运行的旧窗口需重新打开才使用新程序。

硬件编码仍有 CPU 色彩转换和上传，尚非零拷贝；当前目标 1–60 FPS，4K 实测尚不足以持续 60 FPS。没有新增 H.265、AV1、HDR、视频 FEC、Wayland portal 或公网寻址。上游编码依赖的整包开发测试夹具在未修改基线上也无法编译，本版本不将其报告为通过，H.264 局部恢复补丁由实际 GPU 冷解探针验证。
