# Eclipse v0.23.1

本版本按用户要求固定现有功能里程碑，标签先保留本地。下载仍以 GitHub Releases 实际发布为准；创建本地标签不表示已有对应版本安装包或完成全部实机验收。

- 统一暗色设计系统、控件状态和串流菜单外观，增加首次连接引导、设备连接主操作、画质偏好与折叠高级设置。
- 虚拟显示器支持保存创建规格、独立连接与租约，以及后台空闲时的容量准备和应用内首次驱动准备流程。活动输出仍受所有权保护，不强行重载正在使用的驱动。
- 拆分、合并串流窗口时统一异步帧与光标通知的目的窗口，拒绝未声明的临时窗口创建。
- 合并有序输入队列中相邻的鼠标移动，保留按键、按钮、滚轮、坐标模式及授权代次边界。
- GPU 容量暂满时保留原生呈现与最后有效画面，完成后恢复；视频呈现采用非阻塞提交并限制繁忙时重复积压。
- Windows 后台包含登录前控制台启动逻辑、实际运行版本查询、共享启动防火墙检查和缺失规则配置。串流使用固定端口池，普通程序和受保护后台仍需分别更新。

## 验证与已知限制

此前开发包的生成音视频、插件回归、固定端口十流生命周期及真实 GPU 资源容量恢复已通过相应检查。这些结果不等于输入或视频端到端延迟已降低一帧，也不等于所有 Windows 显示环境已经验收。

Windows 可见窗口拆并、首次驱动安装与真实批量目标、双虚拟屏、HDR 切换、冷启动登录屏串流，以及真实4K拖动和相对 Sunshine 的稳定一帧目标仍有未完成的实机验收。有限解码样本池的回收风险也仍需验证。

版本号改变会影响构建身份及插件 SDK；旧开发包保持原文件名和校验和，不能改名作为本版本产物。后续安装应使用重新构建的完整包，保留匹配运行库与插件；后台功能须更新实际 Windows 后台服务后才生效。
