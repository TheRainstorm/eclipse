# v0.20.5

撤销 v0.20.4 在每次实际重绘原生合成 UI 图层后新增的 `glFinish` 阻塞等待，恢复此前的 WGL 共享纹理解锁路径，去除这项额外等待。资源销毁和尺寸变化时已有的同步保持原有生命周期。

后续真实串流验收确认，v0.20.4 没有解决受影响设备的全屏整窗黑屏。该版本的生成像素测试只验证了探针中的 UI 图层现象，不能证明实际故障已修复。全屏黑屏仍在调查，本次版本仅撤销未达到实际修复目标、同时带来开销的处理。

更新完整客户端安装包后，退出旧主页和串流窗口，再打开新版。共享端无需因此重启。插件已静态编译在程序中，使用经过来源与逐文件哈希核验的完整包更新即可。

验证：170 项 GUI 回归通过（3 项隔离测试默认忽略），Windows 全目标编译检查通过。撤销等待后的生产工作区，以本机加密生成视频和硬解执行 1080p 窗口、全屏及退出全屏测试，四个阶段的自有窗口采样点均可见。该测试使用置顶测试窗口，仍未复现用户实际串流的整窗黑屏，不能作为该故障已修复的证据。
