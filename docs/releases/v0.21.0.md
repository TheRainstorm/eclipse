# Eclipse v0.21.0

项目正式统一使用 **Eclipse / 日蚀** 名称，GitHub 主仓库改为 [`TheRainstorm/eclipse`](https://github.com/TheRainstorm/eclipse)。README 以原生串流与独立插件为中心重写，并更新设备列表、串流 HUD / 悬浮菜单及设置的 Windows 实机截图。

- Windows 包名改为 `eclipse-windows-x64-<revision>.zip`，默认安装目录为 `%LOCALAPPDATA%\Programs\Eclipse`，桌面快捷方式显示 Eclipse。升级识别旧快捷方式，只更新属于本应用的目标；同名的其它应用快捷方式保留。
- Linux 包名改为 `eclipse-linux-x86_64-<revision>.tar.gz`，安装到 `~/.local/opt/eclipse`，应用菜单为 Eclipse。保留旧命令及隐藏桌面启动项作为兼容入口。
- 程序继续使用原用户数据目录；安装器更新载荷时保留配置与现有进程。升级原有自定义安装应指定原目录，并退出旧窗口后重新打开。
- 下载工具支持新包名和历史 `uu-client` 包名。发布流水线显式构建原生程序，再执行媒体烟测，修正只生成测试程序时找不到 CLI 的问题。

主程序仍只分发通用引擎和共享运行库，UU 插件在[独立仓库](https://github.com/TheRainstorm/uu-client-plugins)发布，默认关闭。插件与主程序必须使用匹配的 SDK，升级应保留完整包内全部文件。用户已启用的插件和模块配置保持原值。

本版延续 [v0.20.10](v0.20.10.md) 的插件模块和界面行为。输入响应统计、HUD 内容调整以及高帧率延迟 / 卡顿分析列为后续工作，不包含在本版性能结论中。
