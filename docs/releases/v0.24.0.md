# Eclipse v0.24.0

本版本整理多屏串流、自建虚拟显示器和统一主机服务，并改进编码启动、声音与操作反馈。安装包及云端构建状态以 GitHub Releases 和 Actions 的实际结果为准。

## 多显示器与画面设置

- 一台设备在同一窗口显示多个屏签，首次访问时建立对应串流，之后保留连接。屏幕可拆成独立窗口或合并，关闭当前屏幕后按本窗口的访问历史回退。
- 统一关闭屏幕、关闭设备分组和关闭窗口的作用范围；失败页面只关闭当前屏签。初始屏签保持显示器顺序，恢复上次访问的屏幕，Windows 编号使用系统显示源编号。
- 每屏分别保存分辨率、帧率、码率和编码偏好。增加本地分辨率、本地帧率、自定义分辨率以及“不超过本地显示器帧率”选项；默认配置继续跟随远端并按屏幕分配预期带宽。
- 保留客户端显式编码优先级，协商双方支持的回退；编码准备验证实际关键帧，减少自动模式启动时不必要的能力扫描。单路准备失败保持其它连接。

## 自建虚拟显示器

- 统一管理自建临时屏和持久屏，默认上限两个；外部显示器在串流菜单中归入“已有显示器”。
- 创建区常驻，每个显示器横向编辑名称、分辨率、帧率和 HDR；新建显示器自动使用不同的神话名称，保存的旧名称保持。
- 修复串流中首次安装缺失驱动、身份就绪等待、整批预留目标停用和显示目录中间状态问题，避免额外屏签、误判兄弟屏移动和重复重试。
- “检查并恢复准备”核对并收尾已有未完成操作；需要空闲时明确提示。此操作不重新安装驱动或回放历史桌面布局，未确认恢复前保留所有权。

## 声音、服务与界面

- 同窗口同设备保留一个可用音源，切换屏签继续收听；音量和静音共用，拆窗默认静音，关闭音源时由其它连接接替。
- 服务设置增加默认开启的“串流时静音主机扬声器”。控制端继续收听，最后一路声音串流正常结束后恢复原状态，手动调整优先。Windows 操作采集端点，Linux 使用临时静音输出。
- Windows 主机统一使用后台服务及配置；空闲后应用服务更新，零会话重启不再要求多余确认。连接服务只展示实际加载的插件，配对页说明临时和长期 PIN 等授权方式。
- 恢复紧凑 HUD 间距，串流诊断独立居中。壁纸下载使用唯一默认文件名，成功反馈按时消失；会话区域保留空态说明。
- 修复 Windows 空闲窗口持续重绘及 GPU 占用，并为桌面切换后失效的 DXGI 采集增加有界重建。

## 更新与验证范围

使用完整包更新主程序、SDK 和匹配插件，保留现有用户数据；旧进程需要退出并重开。主机功能还需要更新实际运行的 Windows 服务。不要把上一开发版产物改名作为本版本。

已有开发验证覆盖核心和界面回归、生成加密音视频、真实硬编硬解、Windows 可见窗口重绘，以及隔离音频输出恢复。状态测试和生成图不代表所有实体桌面交互均已验收。

高码率下的输入延迟、真实 UAC 授权过程、多路编码器驱动崩溃隔离、各种硬件的 HDR 与长期稳定性仍需继续验证；本版本不承诺这些问题已经全部解决。主机静音和 Linux 临时音频路由依赖正常关闭，进程强杀或崩溃后的独立恢复尚未实现。
