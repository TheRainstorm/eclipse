# v0.20.0

UU 连接服务和兼容协议从原生引擎拆为构建时插件，`plugins/` 由独立公开仓库 [uu-client-plugins](https://github.com/TheRainstorm/uu-client-plugins) 维护。主项目使用 Git 子模块固定经过验证的插件提交；CI、源码扫描和完整包校验覆盖子模块。

新增默认关闭的「官方 UU 客户端连接本机（实验性）」入口，位于服务页的 UU 连接服务设置。键鼠、系统声音及文本剪贴板各有独立许可，保存并重启共享后生效。适配器复用原生有界采集编码、标准 RTP/Opus 和输入所有权，支持 H.264 SDR、CONTROL/TEXT 初始化与基础交互；Windows 增加移动输入法的 Unicode 文本注入。

官方会话绑定近期有效的服务请求及 session/client/control 身份，共用主机并发限额；不取得原生公钥配对或 Eclipse 管理权限。无效的原生 SDP 不降级到官方协议。未实现的屏幕重建、格式/桌面变更和工具能力不返回成功。独立仓库与插件化不改变第三方许可义务。

验证包括核心 282 项与插件 91 项 release 测试、真实 DTLS/SRTP 生成视频、画质应答及拒绝、路由隔离、停止与取消清理，以及默认应用 Windows/Linux 检查。正式官方 Android、iPhone、Windows 客户端互通和真实桌面交互仍待验收；此版本提供实验入口，不宣称手机全部功能已经兼容。详见[兼容范围](../official-mobile-client-feasibility.md)。

升级请使用完整安装包，退出旧主页和串流窗口后重新打开；后台服务也需更新完整程序。源码构建使用递归克隆，或更新后运行 `git submodule update --init --recursive`。GitHub 自动生成的源码压缩包不包含插件源码，不能直接用于构建。
