# Eclipse 0.23.3-dev.20261104

本开发迭代调整设备配置管理、参数页和青蓝配色，按独立提交编号交付，不创建正式发布或覆盖既有标签。

- 每台设备保留多个独立配置。编辑时可从名称列表选择已有配置并加载参数；输入新名称会以当前参数创建新配置。已有名称须从列表明确选择，避免覆盖其它配置。
- 提供配置删除操作。删除当前默认配置后回退全局默认；已建立的连接继续使用启动时的参数。
- 画面与编码页直接展示帧率、分辨率、HDR、垂直同步、解码、视频格式和码率等实际参数，移除简化画质预设及高级折叠入口。已有参数保持原值。
- 配置页沿用悬浮菜单的共享控件样式。
- 配色新增青蓝，与浅色、深色和跟随系统独立选择。默认仍为浅色、原有蓝色配色。

开发包需要主程序、运行库与插件完整配套更新。本轮界面功能不要求重装驱动或重启后台服务。配置与状态测试不能替代真实桌面操作验收。
