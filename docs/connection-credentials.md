# 连接签名配置

## 开发版默认行为

UU 兼容模式默认使用 PC 客户端共享的 HMAC-SHA256 请求签名值，未创建本地签名文件也可开始扫码登录和加载设备。此值与[公开兼容实现中的 PC 默认值](https://github.com/VallierDev/uu-remote-linux/blob/169edf2224775db9e2300fc825ffa08bfc2da428/src/auth.rs#L12)相同，源码明确记录，编译后的程序也可提取；本项目不把它描述为保密数据，不通过编码或混淆隐藏它。

请求签名与账号登录令牌、设备权限、媒体加密和原生配对邀请分别承担不同作用。默认签名值不能替代账号登录或远端授权。公开兼容实现、共享值和本项目许可证均不代表官方接入授权；参见[许可与兼容接入说明](licensing-and-compatibility.md)。

v0.1.0–v0.4.0 发布包仍要求本地签名文件；恢复默认值的改动属于之后的开发版，将随下一版本发布。更新保留现有覆盖文件和登录状态。

## 可选本地覆盖

服务变更或需要指定其它有权使用的配置时，客户端按下列优先级在运行时读取：

1. 环境变量 `UU_SIGNING_KEY_FILE` 指定的文件。
2. 默认数据目录中的 `signing-key`：`$XDG_DATA_HOME/uu-remote/signing-key`；未设置 XDG 时为 `~/.local/share/uu-remote/signing-key`。Windows 默认以用户个人目录作为 `~`。
3. 默认文件不存在时，使用随程序分发的 PC 共享值。

**显式指定的文件不存在，或者文件无法读取、权限过宽、格式错误时，直接显示错误，不悄悄改用内置值。**清除错误的环境变量或修正文件后重试即可。已有覆盖文件优先于默认值，升级不会替换它。

覆盖文件使用 UTF-8 单行文本，可带 UTF-8 BOM 和行尾换行；内容不会写入版本清单、普通设置、日志或错误信息。Unix 文件权限必须仅本人可访问，例如 `600`。不要将覆盖文件放在公开共享目录。

只设置路径，不把文件内容写入命令参数：

```bash
export UU_SIGNING_KEY_FILE="$HOME/.config/uu-client/signing-key"
chmod 600 "$UU_SIGNING_KEY_FILE"
```

```powershell
$env:UU_SIGNING_KEY_FILE = Join-Path $env:USERPROFILE '.config\uu-client\signing-key'
```

环境变量不会自动创建文件；先用本地编辑器创建并保护它。不要在 issue、截图或日志中分享账号令牌、二维码数据、本地覆盖文件或原生邀请。

## 告警与轮换

HMAC 共享值可公开提取，不能承诺它保持机密，也不能承诺 GitHub 或其它平台永不发出提示。安全告警应按实际匹配内容判断；编译器符号误报不等于服务凭据泄露，真实密钥也不能仅因其它项目使用便认定已获分发授权。仓库保留秘密扫描与推送保护。

服务端若更换共享值，本项目内置版本可能失效，可先通过本地覆盖配置更新。服务凭据的撤销和轮换只能由服务方执行。本项目不提供在线签名代办服务，不分发 Web 接口的另一份签名值。原生 Eclipse 模式使用自己的短期邀请与 TLS 配对，不依赖此共享值。
